# 달고나 겉모습: 가열(탄) 정도에 따른 색과 무늬

사용자가 보낸 참고 사진 6장을 보고 정리한 것 (2026-11-17). 게임 구현: `src/client/Making/Dalgona.lua` (`Dalgona.lookFor`, `Dalgona:setLook`).

## 사진에서 본 것
| 사진 | 상태 | 색 | 표면 무늬 | 테두리 |
|---|---|---|---|---|
| 별 (철판 위, 금 간 것) | 잘 된 것 | 연한 황갈색·카멜 | 무광, 고운 설탕 결정 반점(밝은 점), 표면 고름 | 조금 진한 주황 띠 |
| 별 (흰 바탕) | 잘 된 것, 조금 마름 | 밝은 금빛 노랑 | 잔금(흰 결정 줄), 가운데 갈색 얼룩 2~3개 | 울퉁불퉁 도톰함 |
| 모양 4개 | 조금 지나침 | 진한 주황갈색 | 번들거림, 작은 기포 구멍이 많음 | 가장자리로 갈수록 진함 |
| 국자 속 (왼쪽) | 녹이는 중 / 너무 뜨거움 | 진한 호박색 + 밝은 주황 줄 | 끓는 기포 | — |
| 원판 (오른쪽) | 탐 | 적갈색, 가운데는 거품 주황 | 큰 기포, 유리처럼 번들 | 거의 검은 진한 테 |
| 여러 개 비교 | 덜 됨 → 잘 됨 → 지나침 → 탐 | 연노랑 → 황갈 → 적갈 → 흑갈 | 지나칠수록 광택·기포가 커지고 얼룩이 생김 | 지나칠수록 테가 넓고 검어짐 |

## 이해한 규칙
1. **열을 많이 받을수록**(높은 온도에 오래, 소다를 늦게, 소다를 많이) 색이 황갈 → 주황갈 → 적갈 → 흑갈로 어두워진다.
2. **광택**: 잘 된 달고나는 무광(결정 때문), 지나칠수록 캐러멜처럼 번들번들해진다.
3. **기포**: 잘 된 것은 아주 고운 구멍, 지나칠수록 기포가 커지고 위로 볼록 솟는다.
4. **테두리**: 가장자리가 먼저 탄다. 늘 가운데보다 진하고, 탈수록 띠가 넓고 검어진다.
5. **얼룩**: 국자 바닥에 눌어붙은 부분이 갈색·검은 얼룩으로 남는다 (지나칠수록 많고 진함).
6. **소다가 적으면** 덜 부풀어 촘촘하고, 기포가 적고, 투명한 호박색이 된다.

## 게임 수치 (탄 정도 b = 0 ~ 1)
| b | 본체 색 | 테두리 색 | 광택 | 결정 반점 | 기포 | 얼룩 |
|---|---|---|---|---|---|---|
| 0 (Perfect) | (216,146,62) | (186,112,42) | 0 | 많이 | 아주 작게 몇 개 | 없음 |
| 0.35 | (196,116,46) | (150,78,30) | 하이라이트 3 | 조금 | 작은 구멍 많이 | 2~3개 |
| 0.65 | (168,88,40) | (105,48,20) | 하이라이트 7 | 없음 | 볼록한 기포 | 4~5개 진하게 |
| 1 (탐) | (92,42,18) | (38,20,10) | 하이라이트 10 | 없음 | 큰 기포 | 6~7개 검게 |

광택은 Roblox Reflectance를 쓰면 하늘이 비쳐 보라색이 돼서, 밝은 길쭉한 하이라이트 점 개수로 표현한다.

b 계산 (`Dalgona.lookFor`): 녹이기 탄 정도(`burn`) + 온도가 적정 구간을 벗어난 시간 + 소다를 늦게 넣은 시간 + 소다를 많이 넣은 양.
