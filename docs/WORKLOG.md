### 틀 자국 입체감 + 소리 연결 (2026-11-18)
- 참고 사진 `docs/images/stamp_reference.jpg`. 틀 자국이 이제 깊이 있는 V자 홈: 진한 바닥 + 빛 쪽 벽 그림자 + 반대쪽 가는 밝은 줄 → 모양이 도드라져 보임 (`Dalgona:groove`, `Groove:setDepth`).
- 누름판이 닿는 순간부터 홈이 파이고 누를수록 깊어짐 (0.12초 미만 흐림 → 0.12~0.5초 또렷 → 그 이상 넓고 진해짐, 0.85초 넘으면 금). 틀 손잡이 쪽 철사 끝에서 원판 가장자리까지 손잡이 자국. 모든 도안에 같은 방식 (별·하트 확인).
- 소리: 새 모듈 `Making/Sfx.lua` + `C.Sounds` 키 7개 (sugarPour, crack, fire, stirDry, stirCrystal, stirLiquid, stirCream). 설탕 붓기·금 가기·연탄불(국자 높이)·젓기(상태별, 속도 = 크기·재생 속도)에 연결. **ID는 비어 있음** → 사용자가 `docs/SOUND_CANDIDATES.md`에서 고르면 넣음.
- 확인: 하트 한 판 Q 95 Perfect(서버 검증), 오류 없음. 장면 `docs/screenshots/2026-11-18/stamp/` (groove_good, groove_weak, play_heart).

### 소리 ID 넣기 (2026-11-18)
- 사용자가 고른 7개를 `C.Sounds`에 넣음 (`docs/SOUND_CANDIDATES.md` 위 표). AudioAnalyzer로 앞쪽 무음을 재서 `<키>Start`로 건너뜀, 젓기 소리 크기 맞춤.
- Play 확인: 단계마다 들린 소리 — 설탕 붓기 sugarPour, 녹이기 fire + stirDry → stirCrystal → stirLiquid, 소다 fire + stirLiquid → stirCream, 세게 찍기 crack. 소다가 끝난 뒤에도 stirCream이 남는 문제를 찾아 `Sfx.stopStir()`로 고침 (고친 뒤 다시 돌려 보지는 않음).

### 설탕·소다·붓기 다듬기 + 다시 하기 젓가락 (2026-11-18)
- 가루: 동그라미 홈 삭제, 고운 점 220개 (젓가락이 지나가면 밀림). 숟가락으로 붓는 낱알 더 작고 많게.
- 결정 300개 + 밑에 갈색 설탕물이 깔렸다가 녹을수록 차오름 (`SugarLook`). 녹기 시작하면 젓가락 끝에 설탕물이 맺혀 붙어 다님 (`FxTipCoat`, Chosen에 Weld).
- 소다: 통을 누르면 젓가락 끝을 "쿡" 찍고 흰 소다가 묻음 → 국자 위에서 놓으면 툭 떨어져 흰 점. 부풀기는 표면 점(구멍·반짝이·기포) 없이 반죽 덩어리만 커짐.
- 붓기: 붓는 자리를 양으로 가중해 반죽 가운데·길이 방향을 정함 (`Pour.lua`, `Dalgona.yaw`). 길이/폭 1.8 넘으면 실패 (`C.Pour.failSpread`, `Scoring.misshaped`, 서버 필드 `spread`) → 찍기 때 금, 결과 "Fail" Q 15 이하.
- 다시 하기 때 젓가락이 사라지던 버그: 젓가락 모델 기준점이 Stick1이라 되돌릴 때 포장 젓가락이 밀려남 → 부품별 처음 자리로 되돌림 (`Station:restChopsticks`).
- 확인 (Play): 젓가락 끝 설탕물·소다 위치 일치, 2번 찍기, 부풀기, 일직선 붓기 → Fail Q 15 (서버 판정), 다시 하기 후 포장 젓가락 보임. 설탕 단계별 모습은 Edit에서 세움. 장면 `docs/screenshots/2026-11-18/v3/`.

### 국자 높이 조작·탐·누름판 비키기·설탕 모양 (2026-11-18, PM 정리 A~D)
- A 설탕: 숟가락 조작은 그대로, 국자 속 설탕 더미는 설탕 그릇의 더미(SugarHeapMesh)를 복제해 똑같은 모양·재질 (사용자 선택). 낱알 따로 없음.
- B 국자 높이: 화면 왼쪽 24% 구역을 위아래로 끌면 국자가 오르내림 (`Pointer.sideZone`/`takeSideDelta`, `Heat.control`). 폰은 두 번째 손가락으로 젓는 것과 동시에, 마우스는 번갈아. 젓는 원 위치는 이제 높이와 상관없음. 왼쪽에 높이 막대(위 파랑·초록, 아래 빨강, 손잡이). 녹이기·소다 둘 다. Studio 테스트용 `MakingClient.TestSide:Fire(down, x, y)`.
- C 너무 가까우면 탐: 막대 손잡이가 빨갛게, "불에 너무 가까워요 / 타고 있어요" 안내, 탄 정도 속도 1.5배(/40), 연기는 조금만 타도 바로, 설탕 더미도 갈색→검게. Play: 바닥까지 내리면 221°, 몇 초 만에 Burnt(Q 12).
- D 누르기: 한 번 누르고 떼면 누름판이 오른쪽 뒤 위로 비켜 눌린 원판이 보임, 다시 누르면 가운데로 돌아와 내려감 (`Press.lua` aside).
- 확인: 정상 한 판 Q 76 Good(서버 검증, 일부러 태운 시험이라 녹이기 16). 장면 `docs/screenshots/2026-11-18/v4/`.

### 손잡이를 잡고 드래그 + 젓가락 방향 (2026-11-18)
- 손가락이 국자·설탕을 가리지 않게: 손가락 = 도구 손잡이 끝. 젓가락 끝은 손가락 아래 평면에서 화면 위쪽(-Z) 1.2, 손잡이 끝은 손가락 시선 위에서 끝과 2.6 떨어진 점 (`Stir.grip`). 녹이기·소다 젓기·소다 찍어 끌기 모두.
- 설탕 숟가락: 머리는 손가락에서 화면 위쪽 2.0, 손잡이 끝이 손가락 시선 위에 오게 숟가락 방향을 맞추고, 붓기는 손잡이 축으로 굴림 (`Sugar.lua` measureSpoon / gripSpoonCFrame).
- 젓가락이 거꾸로(굵은 쪽으로) 젓던 것: 길이 방향으로 180° 뒤집음. 메시 4개 모두 +X 끝이 가는 쪽(두께 0.097 vs 0.127~0.254)이고, 이제 +X 끝이 국자 안으로 감 (EditableMesh로 확인).
- Play 확인: 숟가락·젓가락 손잡이 끝이 입력 지점과 겹침 (젓가락 10px 안). 장면 `docs/screenshots/2026-11-18/v5/`.
- 테스트 메모: TestPointer에는 `WorldToScreenPoint` 좌표를 그대로 넣는다 (인셋을 빼면 58px 어긋남).
