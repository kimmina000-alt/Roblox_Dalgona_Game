- 6단계 (마우스 = 손가락 하나):
  1. 설탕: 숟가락을 국자 위로 끌면 기울며 쏟아짐(40° 이상). 백설탕 2 → 황설탕 1/4. 밖에 흘리면 알갱이가 남고 감점.
  2. 녹이기: 원을 그리며 젓기, 원의 화면 높이 = 국자 높이(위 = 불에서 멂). 흰 알갱이가 줄고 호박색 → 너무 뜨거우면 갈색 → 검정 + 연기 → Burnt로 바로 끝.
  3. 소다: 분홍 숟가락을 끌어 톡(기울인 시간 = 양) → 빠르게 젓기(FAST가 정답) → 0.5초 만에 불투명하게 부풂.
  4. 붓기: 국자를 철판 위로 끌면 기울어져 덩어리가 떨어짐 → 탭으로 남은 반죽 털기. 원 밖이면 타원으로 찌그러짐.
  5. 누르기: 꾹 누르면 내려가고 떼면 스프링 복귀. 3번 나눠 목표 두께. 너무 얇으면 갈라짐.
  6. 모양: 별 틀을 끌어 가운데에 놓고 살살 누르기. 세게 누르면 금, 약하면 자국이 흐림.
