# 가게 설비 단계 = 달고나 기계의 시대 순서 (2026-11-18 처음 작성, 2026-11-19 확정안으로 고침)

사용자 결정:
- **설비 단계는 실제 달고나 기계가 바뀐 시대 순서를 따른다** (2026-11-18).
- **확정 배치 (2026-11-19, "그렇게 확정")**: 플레이어 레벨 Lv1·10·15·20·25에 5단계. **가정용 미니 메이커는 뺀다.** 4단계는 연속 생산 설비(컨베이어 라인).
- 각 단계는 이전 설비를 **대체**한다 (쌓아 두지 않음). 알바생·기계·공장의 품질은 최고 Excellent까지, **Perfect는 플레이어가 손으로 만들 때만**.

비용·생산량·업그레이드 등 경제 수치는 아직 **기획안**이다. 기준 문서: `docs/SHOP_GROWTH_PLAN.md` (브랜치 `docs/priorities-1117`, 1장·2-1장·5장·6장·12장).
손맛 테스트·저장·판매가 먼저라서 **기계·공장 생산 연결은 아직 하지 않는다** (PM 전달, 2026-11-19).

## 단계 (확정 배치)
| 단계 | 해금 | 설비 | 생산 (기획안) | 품질 | 3D |
|---|---|---|---|---|---|
| 1 | Lv1 | **전통 연탄 화로**. 화로는 그대로, 국자를 Lv3·5·8에 하나씩 늘림 (최대 4개). 첫 국자 = 플레이어 전용(손 미니게임), 나머지 국자 = 알바생이 자동으로 만듦 | 국자 1개당 1개 | 손: Burnt~Perfect / 알바: Normal~Good | 있음 (사용자 모델 `dalgona_wharo.glb`, `dalgona_gukja.glb`). 국자 여러 개 배치는 아직 |
| 2 | Lv10 | **1세대 철제 달고나 판매기**: 스테인리스 윗판 + 열선 화구 2개 + 뒤쪽 금형 견본판(도안 8칸) + 빨간 철판 몸통 + 동전 투입기 3개. 반자동 | 2개 / 30초 | Normal~Excellent | `Era2_*` (+ 알루미늄 국자 `Era2_Ladle`·`Era2_LadleGrip`) |
| 3 | Lv15 | **2세대 분홍 캐릭터 자판기**: 분홍 캐비닛 + 보라 안내판 + 동전기 + 둥근 버튼, 선반에 전기 화구와 검은 누름판·누름 손잡이. 자동 | 5개 / 50초 | Normal~Excellent | `Era3_*` (+ 알루미늄 컵 `Era3_Cup`·꼬치 `Era3_Stick`) |
| 4 | Lv20 | **연속 생산 설비 (컨베이어 라인)**: 기계 한 대 안에서 설탕 공급 → 끓이기 → 노즐 → 컨베이어 → 프레스 → 식힘 → 받는 상자. 완전 자동 | 10개 / 60초 | Normal~Excellent | `L4_*` (아래 "Lv4") |
| 5 | Lv25 | **달고나 자동화 공장**: 공장 건물 + 제어대에서 생산 등록 | 20개(업그레이드로 최대 40) / 100초 | Normal~Excellent (Perfect 없음) | `Factory_*`·`Line_*` (아래 "Lv5") |

- **빠진 것:** 가정용 미니 메이커(예전 Lv4). `tools/blender/machines.py`의 `era4`·`era4_tools`와 `dalgona_machines.glb` 안 `Era4_*` 부품은 쓰지 않는다 (가져올 때 빼도 됨).
- 기획서 표 14("화로 Lv마다 적정 온도 구간 +8%" 등 장비 업그레이드)는 이 설비 단계와 **따로** 산다 (SHOP_GROWTH_PLAN 1장).
- 시대별 손맛 차이(Lv2 열선은 온도 반응이 빠름, Lv3 자판기는 설탕 정량 등)는 2·3단계 조작이 정해질 때 다시 정한다 (승인 필요).

## 레퍼런스
- 사용자 자료: 시대별 변천사 정리 (`images/machines/ref_eras_summary.webp`), 1세대 철제 판매기 윗면·속 (`ref_era2_steel_machine.jpg`, `ref_era2_inside.jpg`), 2세대 분홍 자판기 (`ref_era3_pink_machine.jpg`), 공장 기계 속 (`ref_era5_inside.jpg`: 투명 설탕 통 + 나사식 공급기, 계기판 제어판).
- 직접 찾아본 것 (구글 이미지 검색, 2026-11-18):
  - "달고나 자판기 문방구": 분홍 캐비닛 + 보라 안내판(만화 그림·풍선·구름), 은색 동전기, 둥근 버튼(노랑·파랑·빨강 불빛·흰색), 가운데 움푹한 선반의 왼쪽 알루미늄 컵(설탕 녹이기, 꼬치가 꽂힘)·오른쪽 검은 사각 누름판과 원통 누름 손잡이, 아래 노란 주의 스티커. 2000·2011년 표시된 사진도 있음. "고장 수리" 영상의 스테인리스 판매기(화구 2개)도 같은 계보.
- 4단계(컨베이어 라인)와 5단계(공장)는 실제 달고나 공장 사진을 찾지 못해, 사탕 공장 디포지터 라인(설탕 통 → 솥 → 노즐 → 틀 → 컨베이어)과 사용자 공장 기계 사진을 합쳐 만듦.
- 글 자료: 문방구 달고나 자판기는 연탄 대신 열선이고 동전을 넣으면 설탕이 나오는 방식([thewiki.kr 달고나](https://thewiki.kr/w/달고나)). 1970~80년대 길거리 간식으로 유행.
- 실제 기계의 상표·캐릭터 그림은 따라 그리지 않는다. 3D는 색 면과 단순한 별·구름 무늬만.

## 그림체: 둥글둥글한 파스텔 사탕 공장 (사용자 요청 2026-11-19)
- 사용자가 보낸 그림(파스텔 사탕 공장 아이소메트릭)처럼 **둥글둥글하고 귀엽게**. 그림을 베끼지 않고 느낌만 따름.
- `factory.py` 공통: 모든 상자 모서리를 둥글림(가장 짧은 변의 22%, 3단), 파스텔 색(민트·분홍·하늘·레몬·연보라), 금속은 은은한 펄, 위험 줄무늬 → 분홍·흰 사탕 줄무늬, 바닥 = 연노랑·연분홍 바둑판 타일, 벽 = 위 민트 + 아래 분홍, 흰 창살, 남색 벨트.
- 장식: 기계 머리 위 사탕 공, 커다란 막대사탕, 흰 울타리(둥근 말뚝), 잔디 띠와 둥근 덤불, 앞 모서리 무지개 고리 사탕 기둥 2개 (`Deco_*`, Lv4는 `L4_Deco*`).

## Lv4 연속 생산 설비 (컨베이어 라인, 2026-11-19)
- 스크립트: `tools/blender/factory.py` 의 `build_line` (실행 끝에 `line`) → `레퍼런스/line/dalgona_line.glb` (+ `line_parts.txt`). 미리 보기 `images/machines/line_preview.png`, `line_panel.png`. 부품 39개, 삼각형 약 8,800.
- 크기: 길이 약 12 (받는 상자까지) · 깊이 3.4 · 높이 약 6.3 (설탕 통 꼭대기). 바닥에 놓는 기계. 원점 = 바닥 가운데, 앞(플레이어 쪽) = Blender -Y.
- 구성 (왼→오): 민트 칠 받침 캐비닛(흰 점검 문 4개) 위에 투명 설탕 통 → 솥 1개(빨간 가열 띠·계기) → 노즐대(노즐 3개) → 컨베이어(2×2칸 틀 쟁반) → 작은 프레스(사탕 줄무늬 옆판, 실린더 1개, 도장판 `L4_PressStamps`) → 둥근 식힘 덮개 → 미끄럼판 → 받는 상자. 앞에 조작판 `L4_ControlPanel`(공장 제어판과 같은 그림: 계기 3개 + 도안 버튼 6개), 시작·정지 버튼, 3색 경고등.
- 공장(Lv5)보다 작고 사람 키 높이의 기계 한 대 → "가게 안 설비" 느낌, 공장은 "건물" 느낌으로 구분.
- 기획안 기능 (SHOP_GROWTH_PLAN 5장): 재료 자동 공급, 연속 성형·냉각, 완제품 자동 수거, 생산 작업 2개 대기열. 업그레이드(병렬 생산·대형 저장고·고속 컨베이어)는 기획안.

## Lv5 달고나 자동화 공장
- 스크립트: `tools/blender/factory.py` → `레퍼런스/factory/dalgona_factory.glb` (+ `factory_parts.txt`, 미리 보기 `images/machines/factory_preview.png`, `factory_console.png`). 부품 72개, 삼각형 약 6.1만 (가장 큰 부품 울타리 약 1.7만, Roblox 메시 한 개 한도 2만 안).
- 크기: 공장 바닥 44 × 28, 벽 높이 16 (뒤·왼쪽 벽만, 앞·오른쪽은 카메라·플레이어 쪽이라 열어 둠). 원점 = 바닥 가운데.
- 생산 라인 (왼→오): 설탕 저장 탑(투명 통 2개·철골·사다리·공급관) → 끓이는 솥 2개(스테인리스 + 빨간 가열 자켓·계기·밸브) → 반죽 노즐대(노즐 6개) → 컨베이어(벨트 24 길이, 2×3칸 틀 쟁반) → 찍는 프레스(위험 줄무늬 기둥, 유압 실린더 2개, 도장판 `Line_PressStamps`) → 식히는 터널(환풍기·비닐 커튼) → 미끄럼판 → 받는 상자 3개.
- 제어대 `Line_ConsolePanel`: 계기판 3개 + 도안 고르기 버튼 6개(별·하트·원·세모·우산·네모) + 표시줄, 시작(초록)·정지(빨강) 버튼, 3색 경고탑.
- 텍스처 (스크립트가 numpy로 그려 glb에 넣음): 솔질 스테인리스, 위험 줄무늬, 고무 벨트, 콘크리트 바닥 줄눈, 벽 칠(아래 초록 띠), 창문, 제어판 면. Roblox로 가져오면 MeshPart TextureID로 들어옴. 금속감은 빌더가 `Material`을 `factory_parts.txt` 대로 칠함.
- Studio: `ServerStorage.Assets.Factory`로 가져옴(2026-11-18). 서버 시작 때 `FactoryBuilder.place(workspace, CFrame.new(0,0,30))`가 스폰 뒤에 공장을 놓음(제어대가 스폰 쪽). 재질·색·투명도·천장 조명 6개는 `FactoryBuilder.style`이 넣음.
- 이용 순서 (확정 기획안, SHOP_GROWTH_PLAN 6장): 제어대 누르기 → 도안 고르기 → 수량(20 / 40) → 생산 방식(일반 / 정밀 1.5배 시간 / 고속 0.7배 시간) → 시작 → 컨베이어에서 하나씩 만들어지는 연출 → 완제품은 재고 창고로.
  - 예전 안 "한 번에 4개, Excellent 고정"은 **폐기**. 품질은 방식에 따라 Normal~Excellent, Perfect 없음.
- 도안을 바꾸면 `Line_PressStamps`·`Line_Dalgona`(프레스 지난 것)·`Line_CrateDalgona`를 고른 도안 모양으로 바꿔 끼움 (지금은 별).

## 3D 파일 (2·3단계)
- 만드는 스크립트: `tools/blender/machines.py` → `레퍼런스/machines/dalgona_machines.glb` (+ `machines_preview.png`, `machines_parts.txt`).
- 크기 = 게임 stud. 기계 기준점 = 바닥 가운데(테이블 윗면에 놓음), 앞 = 플레이어 쪽. 화구 높이는 지금 철망(테이블 위 약 3.8)과 비슷하게 맞춤 → 국자 높이 조작이 그대로 맞음.
  - Lv2(2단계): 폭 5.4 · 깊이 3.6 · 높이 3.7 (+ 뒤쪽 견본판 1.4), 화구 2개 x ±1.45.
  - Lv3(3단계): 폭 4.6 · 깊이 3.4 · 높이 5.8, 선반 높이 3.0, 화구(왼쪽)·누름판(오른쪽).
  - 같은 파일의 `Era4_*`(가정용 메이커)와 `Era5_*`(예전 작은 공장 기계)는 **쓰지 않음** (각각 `L4_*`, 공장으로 바뀜).
- 부품마다 색·Roblox 재질·기준점에서 경계 상자 가운데까지 거리를 `*_parts.txt`에 적어 둠 (glb 금속도·거칠기는 Roblox로 안 넘어가서 빌더가 색·재질을 직접 칠함).

## 다음
1. 사용자가 `레퍼런스/machines/dalgona_machines.glb`(2·3단계, `Era2_*`·`Era3_*`만)와 `레퍼런스/line/dalgona_line.glb`(4단계)를 Studio로 가져옴 → `ServerStorage.Assets.Machines` (도구는 클라이언트도 쓰므로 `ReplicatedStorage.Assets.MachineTools`).
2. 1단계 국자 늘리기(화로 위 국자 2~4개 자리)와 알바생이 젓는 모습 — 성장·저장 시스템이 생긴 뒤.
3. 단계 바꾸기 `Builder.setMachine(ws, 단계)`, 상점·저장·판매 연결은 손맛 테스트·저장·판매 다음 (PM 순서).
