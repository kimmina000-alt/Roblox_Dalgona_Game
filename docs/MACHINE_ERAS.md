# 달고나 기계 업그레이드 = 시대별 기계 순서 (2026-11-18)

사용자 결정: **기계 업그레이드는 실제 달고나 기계가 바뀐 시대 순서를 그대로 따른다.**
작업대의 열원(지금 연탄 화로 자리)이 업그레이드마다 다음 시대 기계로 바뀌고, 같이 쓰는 도구(국자·컵·냄비 등)도 그 시대 것으로 바뀐다.

## 레퍼런스
- 사용자 자료: 시대별 변천사 정리 (`images/machines/ref_eras_summary.webp`), 1세대 철제 판매기 윗면·속 (`ref_era2_steel_machine.jpg`, `ref_era2_inside.jpg`), 2세대 분홍 자판기 (`ref_era3_pink_machine.jpg`).
- 직접 찾아본 것 (구글 이미지 검색, 2026-11-18):
  - "달고나 자판기 문방구": 분홍 캐비닛 + 보라 안내판(만화 그림·풍선·구름), 은색 동전기, 둥근 버튼(노랑·파랑·빨강 불빛·흰색), 가운데 움푹한 선반의 왼쪽 알루미늄 컵(설탕 녹이기, 꼬치가 꽂힘)·오른쪽 검은 사각 누름판과 원통 누름 손잡이, 아래 노란 주의 스티커. 2000·2011년 표시된 사진도 있음. "고장 수리" 영상의 스테인리스 판매기(화구 2개)도 같은 계보.
  - "달고나 메이커 가정용": 파스텔(분홍·흰·민트) 둥근 미니 전기 화구 + 은색 링 + 검은 나선 열선 + 금색 다이얼, 스테인리스 손잡이 냄비(나무 손잡이), 동그란 누름판, 도안 틀·헤라·꼬치가 든 세트.
- 글 자료(웹 검색): 문방구 달고나 자판기는 연탄 대신 열선이고 동전을 넣으면 설탕이 나오는 방식([thewiki.kr 달고나](https://thewiki.kr/w/달고나)). 1970~80년대 길거리 간식으로 유행.
- 실제 기계의 상표·캐릭터 그림은 따라 그리지 않는다. 3D는 색 면과 단순한 별·구름 무늬만.

## 업그레이드 순서 (기계 Lv)
| Lv | 시대 | 기계 | 같이 쓰는 도구 | 3D |
|---|---|---|---|---|
| 1 | 1950~1980년대 | 연탄 화로 + 철망 | 구리 국자, 나무젓가락, 둥근 누름판(나무 손잡이), 철사 틀 | 있음 (사용자 모델 `dalgona_wharo.glb`, `dalgona_gukja.glb`) |
| 2 | 1990~2000년대 초 | **1세대 철제 달고나 판매기**: 스테인리스 윗판 + 열선 화구 2개 + 뒤쪽 금형 견본판(도안 8칸) + 빨간 철판 몸통 + 동전 투입기 3개 | 알루미늄 국자 + 초록 플라스틱 손잡이 | `Era2_*`, `Era2_Ladle`·`Era2_LadleGrip` |
| 3 | 2000년대 후반~2010년대 | **2세대 분홍 캐릭터 자판기**: 분홍 캐비닛 + 보라 안내판 + 동전기 + 둥근 버튼, 선반에 전기 화구와 검은 누름판·누름 손잡이 | 알루미늄 녹이는 컵 + 나무 꼬치 | `Era3_*`, `Era3_Cup`·`Era3_Stick` |
| 4 | 2020년대 | **가정용 미니 달고나 메이커**: 파스텔 둥근 전기 화구 + 금색 다이얼 | 스테인리스 손잡이 냄비(나무 손잡이), 동그란 누름판, 헤라 | `Era4_*`, `Era4_Pan`·`Era4_PanHandle`·`Era4_Presser`·`Era4_Scraper` |

기획서 표 14("화로 Lv마다 적정 온도 구간 +8%")는 그대로 기계 Lv에 붙인다. 시대별로 손맛이 조금씩 달라지는 안(승인 필요):
- Lv2 열선: 온도가 연탄보다 빨리 오르내림 → 높이 조작 반응이 빠름. 화구 2개라 한 판 끝나면 다음 판 준비가 빠름(대기 시간 감소).
- Lv3 자판기: 동전을 넣으면 설탕이 정량으로 나옴 → 설탕 단계 실수가 줄어듦(설탕 점수 하한), 누름판이 레버라 누르기 구간 +.
- Lv4 가정용 메이커: 다이얼로 온도를 고름(높이 대신 다이얼) → 적정 온도 구간이 가장 넓음, 냄비 손잡이가 길어 붓기 쉬움.

## 3D 파일
- 만드는 스크립트: `tools/blender/machines.py` → `레퍼런스/machines/dalgona_machines.glb` (+ `machines_preview.png`, `machines_parts.txt`).
- 크기 = 게임 stud. 기계 기준점 = 바닥 가운데(테이블 윗면에 놓음), 앞 = 플레이어 쪽. 화구 높이는 지금 철망(테이블 위 약 3.8)과 비슷하게 맞춤 → 국자 높이 조작이 그대로 맞음.
  - Lv2: 폭 5.4 · 깊이 3.6 · 높이 3.7 (+ 뒤쪽 견본판 1.4), 화구 2개 x ±1.45.
  - Lv3: 폭 4.6 · 깊이 3.4 · 높이 5.8, 선반 높이 3.0, 화구(왼쪽)·누름판(오른쪽).
  - Lv4: 지름 3.4 · 높이 1.1 (작은 기계라 테이블 위 받침이 필요할 수 있음).
- 부품마다 색·Roblox 재질·기준점에서 경계 상자 가운데까지 거리를 `machines_parts.txt`에 적어 둠 (glb 금속도·거칠기는 Roblox로 안 넘어가서 빌더가 색·재질을 직접 칠함).
- 미리 보기: `images/machines/machines_preview.png`.

## 다음
1. 사용자가 `레퍼런스/machines/dalgona_machines.glb`를 Studio로 가져옴 → `ServerStorage.Assets.Machines` 폴더 (도구는 클라이언트도 쓰므로 `ReplicatedStorage.Assets.MachineTools`).
2. 빌더에 `Builder.setMachine(ws, lv)`: 화로 자리의 기계와 국자·도구를 Lv에 맞게 바꿈 (방향은 가져온 뒤 화면으로 확인, glb 앞뒤 뒤집힘 주의).
3. 업그레이드 상점·저장(성장 단계)과 시대별 손맛 차이는 기획 승인 뒤.
