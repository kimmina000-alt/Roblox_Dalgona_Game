# 아트 및 에셋 가이드

상태: 대화 기반 아트 방향 제안. 최종 스타일 가이드는 실제 게임 화면 테스트 후 확정한다.

## 1. 세계관/환경
- 배경: 한국의 레트로 골목시장과 작은 달고나 가게.
- 분위기: 따뜻하고 친근한 동네 상점, 복고 소품과 간판.
- 게임 표현: Roblox에서 실루엣이 읽히는 단순하고 선명한 저폴리곤 스타일.
- 가게 내부는 작업대/화로/판매대/손님 동선이 명확해야 한다.

## 2. 제작 도구 3종
### 국자
- 둥근 금속 그릇과 길고 얇은 손잡이.
- 손잡이 끝 고리.
- 은색 또는 사용감 있는 회색 금속.
- Blender: 얕은 그릇 메시 + 원기둥 손잡이. 내부 면을 확보한다.

### 눌림판
- 얇고 평평한 원형 금속판.
- 중앙 손잡이, 가장자리 bevel.
- 게임에서 수직으로 내려오는 애니메이션이 가능하도록 피벗/축을 정리한다.

### 찍기 틀
- 공통 손잡이와 베이스, 도안별 스탬프 형상을 분리.
- 각인면은 실제로 달고나에 모양이 찍히는 구조로 설계.
- 하트/별/우산/꽃 등 도안마다 교체 가능한 형상 파츠 사용.
- 도안 모델을 한 덩어리로 중복 제작하기보다 공통 부품을 재사용한다.

## 3. 3D 제작 파이프라인
1. Blender에서 저폴리곤 모델링.
2. 모델의 실제 크기/축/Pivot 정리.
3. FBX로 내보내기.
4. Roblox Studio 3D Importer로 가져오기.
5. Tool 또는 Model로 구성.
6. 손잡이 기준 Grip/Pivot 조정.
7. 애니메이션과 상호작용 구현.
8. 모바일/저사양 환경에서 렌더링과 충돌 테스트.

초기 삼각형 수 목표 제안:
- 국자 100~300
- 눌림판 100~250
- 찍기 틀 100~400
- 복잡한 도안 틀 300~600
이는 프로젝트 초기 목표치이며 고정 엔진 제한이 아니다.

## 4. 달고나 결과물
품질에 따라 기본 모델에 다음 시각 요소를 적용한다.
- Burnt: 짙은 갈색, 탄 자국.
- Poor: 불균일한 색/깨진 부분.
- Normal: 일반 갈색.
- Good: 균일한 색과 각인.
- Excellent: 매끈한 표면, 선명한 각인.
- Perfect: 특별한 광택/완성 효과.

MVP는 품질마다 별도 고폴리곤 모델을 만들기보다 기본 메시의 재질/색상/데칼/효과를 변경한다.

## 5. 도안 카탈로그
| 등급 | 도안 |
|---|---|
| Common | 동그라미, 네모, 세모 |
| Uncommon | 하트, 별, 우산 |
| Rare | 꽃, 물고기, 새 |
| Epic | 나비, 비행기, 십자가 |
| Legendary | 검, 범선, 문어 |
| Mythic | 궁궐, 호랑이, 용 |

일부 도안은 게임용 오리지널 창작이다. 전통 도안의 공식 목록/등급으로 홍보하지 않는다.

## 6. 에셋 최적화
- 불필요한 내부 면 제거.
- 장식용 작은 부품 최소화.
- 복잡한 MeshPart 충돌 대신 단순 충돌체 사용.
- 반복 도구는 공통 메시/재질 재사용.
- NPC와 도구 애니메이션은 네트워크/서버 부하 고려.
- 모델 크기와 손잡이 위치를 Roblox 캐릭터에 맞춰 테스트한다.
