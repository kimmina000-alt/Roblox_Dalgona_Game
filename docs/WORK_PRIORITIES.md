## 2-1. 2026-11-18 작업 (사용자 요청, 제작 화면 세션 담당) 🔧

손맛 테스트(10번) 전에 조작을 고치는 것이라 Phase 1 안의 일이다.

| # | 내용 | 메모 |
|---|---|---|
| A | **설탕 시작**: 설탕 컵(양은 그릇)에 담긴 설탕 더미 모습이 좋음 → 그 더미를 그대로 국자에 넣는 것으로 설탕 단계를 시작 | 지금 설탕 단계(숟가락으로 떠서 붓기)를 이 방식에 맞춰 바꿈 |
| B | **국자 높이를 드래그로**: 왼쪽 화면 구역에서 위로 드래그 = 국자를 불에서 올림, 아래로 드래그 = 불 가까이 내림 | 지금은 "젓는 원의 화면 높이 = 국자 높이"로 되어 있음 → 위아래 드래그로 높이를 따로 조절하게 |
| C | **불에 너무 가까우면 탐**: 국자를 들고 불 위에서 저을 때 불에 너무 가깝게 두면 타게 | 탄 정도(색 → 갈색 → 검정 + 연기 → Burnt)는 이미 있음 → B의 높이와 확실히 이어지는지, 눈에 잘 보이는지 확인 |
| D | **누른 뒤 확인**: 반죽을 붓고 누름판으로 누른 다음, 누름판을 살짝 옆으로 옮겨 눌린 달고나를 볼 수 있게 | 누르기 3번 사이·끝에 눌린 상태가 보여야 다음 누르기 판단이 됨 |
