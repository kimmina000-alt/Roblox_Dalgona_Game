# 대화 결정 기록 및 미확정 사항

이 문서는 지금까지의 기획 대화를 프로젝트 기록으로 보존한다. 사용자가 명시적으로 선택한 항목과 어시스턴트가 제안한 내용을 구분한다.

## 1. 사용자가 확정한 결정
| 항목 | 결정 |
|---|---|
| 제작 방식 | 미니게임 중심 |
| 카메라 | 3인칭 |
| 판매 방식 | NPC 자동 방문 |
| 프로젝트 저장소 | kimmina000-alt/Roblox_Dalgona_Game |

## 2. 대화에서 제안된 게임 방향
- 프로젝트명: Dalgona Tycoon / 달고나 타이쿤.
- 한국 레트로 골목시장/달고나 가게.
- 핵심 재미 목표: 직접 제작 40%, 가게 성장 40%, 수집/꾸미기 20%.
- 제작 과정: 설탕 가열 → 소다 혼합 → 압착 → 도장.
- 품질 등급: Burnt, Poor, Normal, Good, Excellent, Perfect.
- 개인 Plot, NPC 자동 판매, 재료/재고, 직원 자동 생산, 레벨/도안/업그레이드.
- 직원은 직접 제작을 대체하지 않는 보조 기능.
- 오프라인 직원 생산/급여는 MVP에서 하지 않는 안.

## 3. 레퍼런스 기록
대화에서는 사용자 제공 영상 두 개를 참고 대상으로 언급했다.
- 캔디 제작 게임 영상: 단계별 제작, 주문/판매, 도감/성장 요소.
- 소금빵 가게 게임 영상: NPC, 시간 기반 생산, 장비/가게 성장, 직원/영업.
원본 영상 세부 장면과 정확한 시스템을 다시 확인하기 전까지는 참고 방향으로만 기록한다. 영상의 실제 내용이라고 과장하지 않는다.

## 4. 대화에서 제안된 도구/아트 방향
- 국자: 금속 그릇 + 긴 손잡이.
- 눌림판: 원형 평판 + 손잡이.
- 찍기 틀: 공통 손잡이/베이스 + 도안별 각인 형상.
- Blender에서 저폴리곤 모델링, FBX로 내보내고 Roblox Studio Importer로 가져오는 파이프라인.
- 실제 게임용 도구는 손잡이 Pivot/Grip과 애니메이션을 고려한다.

## 5. 미확정/검증 필요
1. 게임의 최종 이름/로고/브랜드 컬러.
2. 맵 규모, 가게 수, 플레이어 서버 최대 인원.
3. 미니게임의 구체 조작, 단계별 제한 시간, 실패 규칙.
4. 점수 계산식과 품질 배율의 최종 수치.
5. NPC 이동 방식, 동시 손님 수, 손님 선호도.
6. 상품 FIFO 외 판매 우선순위.
7. 도안별 실제 난이도와 제작 가능 레벨.
8. 재료/원가 표의 불일치: 기본 재료 원가 5와 등급별 Epic 7/Legendary 8/Mythic 12 차이.
9. 판매 가격 반올림 규칙.
10. 직원 급여/생산 주기와 NPC 수요에 따른 실수익.
11. 직원 자동 생산 시 어떤 도안을 생산할지, 플레이어가 지정 가능한지.
12. 직원 슬롯과 작업대 수의 관계.
13. 가게 레벨과 플레이어 레벨의 관계.
14. 장비 업그레이드의 구체 효과.
15. 주문 시스템을 MVP에 포함할지 여부.
16. 고급 포장지의 실제 기능/가격.
17. 모바일 UI와 터치 조작 설계.
18. 제작 도구의 최종 모델 스타일/실제 크기/애니메이션.

## 6. 이전 대화의 수치 오류/주의
- 직원 수익 계산은 대표 도안, Good 품질, 재료비 단순 가정, 전량 판매를 전제로 한 추정치다. NPC 판매 수요와 재고 제한을 반영하면 실제 순수익은 달라진다.
- 등급별 원가표는 현재 재료 가격표만으로 완전히 설명되지 않는다. 추가 재료 또는 원가 규칙이 정의될 때까지 구현 상수로 확정하지 않는다.
- 직원 급여는 분당 요율을 초 단위로 누적 계산하는 방식이 적절하며, 소수점 잔액을 버리지 않는다.
- 도안 등급/목록은 게임 밸런스 제안이며 전통 달고나의 공식 등급표가 아니다.
