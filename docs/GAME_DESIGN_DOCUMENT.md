## 0. 한 줄 정의

> 한국 레트로 골목의 내 달고나 가게에서, 연탄불 위 구리 국자로 설탕을 녹이고 소다로 부풀려 붓고 눌러 모양을 찍어 **손으로** 달고나를 만든다. 손님 NPC가 와서 사 가고, 그 돈으로 국자와 알바생을 늘리고, 시대별 달고나 기계를 거쳐 공장까지 키운다.

| 항목 | 내용 | 상태 |
|---|---|---|
| 플랫폼 / 장르 | Roblox / 제작 미니게임 + 타이쿤 + 수집 | 확정 |
| 이름 | **달고나 골목 (Dalgona Alley)**. 문서 일부에 남은 "Dalgona Tycoon"은 옛 가제 | 확정 (D15) |
| 제작 방식 | 미니게임 중심, 직접 손으로 | 확정 |
| 카메라 | 3인칭. 제작 중에는 단계마다 작업대를 가까이 비추는 고정 카메라 | 확정 (만듦) |
| 판매 | NPC 손님이 자동으로 와서 진열된 재고를 삼 | 확정 |
| 재미 비중 목표 | 직접 제작 40 / 가게 성장 40 / 수집·꾸미기 20 | 기획안 |
| 기기 | PC + 폰 (가로). 모든 조작은 탭·누르기·드래그 | 확정 (만듦, 폰 재확인 남음) |

### 지키는 원칙
1. **손으로 만드는 것이 이 게임의 중심이다.** 자동화(알바생·기계·공장)는 양과 편의를 주고, **Perfect(1.7배)와 최고 도안은 손으로만** 나온다. — 확정 원칙 (`SHOP_GROWTH_PLAN.md` 0장, 사용자 대화)
2. **숫자만 바뀌는 미니게임 금지.** 조작 결과가 국자 속 설탕, 반죽, 달고나 모양으로 눈앞에서 바뀌어야 한다. — 확정 (만듦)
3. **돈으로 제작을 건너뛰게 하지 않는다.** (10장) — 확정 원칙
4. 돈이 무한히 늘지 않게: 재료, 창고, 손님 수요가 생산을 묶는다. — 기획안 (7장)
5. 코인·재고·품질은 서버가 정한다. — 확정 (만듦: 제작 점수 서버 재계산)
6. 실제 상표·오징어 게임 IP는 쓰지 않는다. 달고나 뽑기는 전통 놀이라서 쓴다. — 확정

## 2. 제작 미니게임 (만든 그대로)

작업대 앞에서 E(폰은 버튼) → 나무젓가락 고르기 → 도안 고르기 → 6단계 → 결과 화면. — **확정 (만듦)**

### 2-1. 작업대 구성 (만듦)
연탄 화로 + 철망(사용자 모델, 연탄은 한 판마다 0.1씩 닳고 다 타면 다음 판에 새 연탄, 비용 없음), 구리 국자(사용자 모델, 플레이어 아바타의 오른팔이 손잡이를 잡음), 나무젓가락(포장지를 찢고 쪼개는 연출), 양은 설탕 그릇·소다 깡통·숟가락, 검은 철판, 누름판, 도안 틀 23종.

### 2-2. 단계

| # | 단계 | 조작 (마우스 = 손가락) | 점수에 들어가는 것 | 실패 |
|---|---|---|---|---|
| 0 | 젓가락 고르기 | 포장지 찢기 → 젓가락 쪼개기 (연출) | — | — |
| 0 | 도안 고르기 | 23종 중 고름 (지금은 전부 열림) | 가격 | — |
| 1 | 설탕 넣기 | 숟가락으로 그릇에서 떠서 국자 위에서 멈추면 기울어 쏟아짐. 백설탕 2 + 황설탕 1/4 | 정량에 가까움 + 흘린 양 | 흘리면 감점 |
| 2 | 녹이기 | 국자 안에서 원을 그리며 젓기(STIR SPEED). **화면 왼쪽 구역 위아래 드래그 = 국자 높이**(높이 막대, 폰은 두 손가락). 가루 → 결정 → 반쯤 녹음 → 투명한 액체 4단계 | 젓기 속도 적정 비율 + 온도 적정 비율 − 눌어붙음 − 탐 | 불에 너무 가까우면 빨간 경고 → **Burnt**(Q 20 이하로 끝) |
| 3 | 소다 | 젓가락 끝을 소다 깡통에 찍어 묻힘 → 국자 위에서 놓아 떨어뜨림(횟수 = 양) → 빠르게 저으면 실제 영상처럼 부풀어 오름 | 넣은 타이밍(다 녹고 2초 안 만점) + 양(알맞음 0.35~0.65) + 부푼 정도 | 너무 많음 = 진한 색·감점, 불 위에서 저음 = 탐 |
| 4 | 붓기 | 국자 손잡이를 끌어 철판 위 설탕 원으로 가져가 기울임. 점성 있는 줄기로 떨어짐. 길쭉하면 젓가락으로 양끝을 가운데로 모을 수 있음 | 원 가운데와의 거리 + 국자에 남은 양 + 모양(길이/폭) | 길이/폭 1.8 넘음 = **Fail**(틀이 안 맞음, Q 15 이하) |
| 5 | 누르기 | 누름판을 집어 반죽 위에서 가만히 누르고 있으면 내려감. 3번 나눠 누름. 누른 뒤 누름판이 비켜 눌린 원판이 보임 | 3번 모두 목표 두께(0.25 / 0.14 / 0.08) | 너무 얇음 = 가장자리 갈라짐 −35 |
| 6 | 모양 | 틀을 끌어 원판 가운데에 놓고 누름판으로 살살 짧게 누름. V자 홈 자국 | 중심 50% + 각도 20% + 누른 세기 30% | 너무 오래 누름 = 금 −20 |
| 7 | 뽑기 (선택) | 바늘로 선 따라 긁기. 언제든 "그만하고 팔기" | 따라간 비율, 금 개수 | 쪼개짐 → **못 팖** (보관함에서 빠짐) |

- 1~6단계: **확정 (만듦)**. 효과음 7개(사용자 고름), 단계별 카메라, 폰 레이아웃 포함.
- 7단계 뽑기: **MVP에 선택 단계로 넣기 확정 (D2)**, 만듦 (main, 서버 검증). 성공 보상·실패 규칙은 8장 (D22).
- 한 판 목표 시간 35~45초(뽑기 제외). 옛 문서의 20~35초는 버림. 실제 시간은 손맛 테스트(U2)에서 잼. — 기획안
- 도안별 난이도(도장 판정 폭, 뽑기 선 길이·곡률)는 아직 전부 같음. — 미정 (Phase 1 남은 일)

### 2-3. 품질 판정 (만듦, `src/shared/Scoring.lua`·`DalgonaConfig.lua`)

Q = 0.25T + 0.20M + 0.25P + 0.30S, T = 설탕 20% + 녹이기 80%, P = 붓기 30% + 누르기 70%. 정수로 반올림. 서버가 입력 기록으로 다시 계산하고 서버 점수를 씀(단계당 최소 1.5초).

| 등급 | Q | 가격 배율 | 상태 |
|---|---:|---:|---|
| Perfect | 95–100 | 1.7 | 확정 (만듦) |
| Excellent | 85–94 | 1.3 | 확정 (만듦) |
| Good | 70–84 | 1.0 | 확정 (만듦) |
| Normal | 50–69 | 0.8 | 확정 (만듦) |
| Poor | 30–49 | 0.5 | 확정 (만듦) |
| Burnt | 0–29 (탔으면 Q ≤ 20) | 0.2 | 확정 (만듦) |
| Fail | 모양 실패 (Q ≤ 15) | 0.2 | 확정 (만듦) — **옛 문서에 없던 등급, 이 문서에서 추가** |

- 별 3개: Q 50 / 70 / 85 이상. 판매가 = round(도안 가격 × 배율). — 확정 (만듦)
- 뽑기는 Q·판매가에 안 들어감. 성공하면 덤 달고나, 쪼개지면 못 팖 (8장, D22). 옛 "판매가 × (1 + 0.5 × 정확도)" 보너스는 없앰.

- 옛 문서의 Mythic "궁궐·용"은 실제로 만든 "궁전·공룡"으로 바꿈 (용 틀 대신 공룡 틀이 만들어짐).

- 지금은 저장이 없어 23종이 전부 열려 있다. 해금은 Phase 4.
- 게임 오리지널 도안이 섞여 있다. 전통 달고나의 공식 등급표처럼 홍보하지 않는다.

### 3-2. 도감 (기획안, Phase 4)
- 도안 × 최고 등급을 기록 (예: 별 — Excellent). 처음 만든 도안, 처음 Perfect, 처음 완벽 뽑기 때 결과 화면에 "도감 등록" 표시.
- 손으로 만든 것과 자동 생산은 따로 센다 (도감·랭킹은 손으로 만든 것만).
- **Master 해금 — 확정 (D6):** 레벨이 아니라 도감 조건. 손으로 Excellent 이상 만든 Mythic **종류 수** 1 / 2 / 3 → 거미 → 삼각형 속 삼각형 → 눈꽃, **연꽃 문양 = Mythic 3종 모두 손으로 Perfect**. 알바생·기계로 만든 것은 안 셈. Master는 자동 생산 불가. (2026-11-20 구현 세션과 맞춤)

## 4. 가게 성장 (야외 노점 → 월세 가게 → 국자·알바생 → 시대별 기계 → 공장)

가게 확장은 **달고나를 만드는 방식이 시대에 따라 바뀌는 것**이다. 수치 근거는 `SHOP_GROWTH_PLAN.md`.

### 4-0. 야외 노점 → 월세 가게 → 기계 (확정 방향 2026-11-21, 수치 기획안, D21)

사용자 결정: **처음에는 야외에서 뽑기(달고나)를 팔고, 돈이 모이면 가게에 월세로 들어가고, 그다음에 기계를 산다.**

| 순서 | 언제 | 모습 | 할 수 있는 것 |
|---|---|---|---|
| 야외 노점 | Lv1, 무료 | **내 부지의 가게 건물 바로 앞**에 연탄 화로 작업대 + 파라솔 + 낮은 의자 + 달고나 쟁반. 건물은 셔터가 내려져 있고 "임대 문의" 종이가 붙어 있음 (확정: 자리) | 손 제작, 쟁반 진열 5칸, 손님은 국자 1개 수요(30초 × 1개). 국자 확장·알바생·작업대 업그레이드는 안 됨 |
| 가게 임대 | Lv3 + **보증금 1,000** | 셔터가 올라가고 가게 안이 열림. 손 작업대는 **가게 앞 그 자리 그대로**(옛 가게처럼 화로는 문 앞), 가게 안 = 진열대 10칸·알바생 국자·기계 자리 | 국자 확장(Lv3~8)·알바생·작업대 업그레이드·도감 진열. 수요는 국자 수 표(5-1) |
| 기계 | Lv10~ (가게 임대 중이어야 함) | 가게 안 기계 자리 1곳 (D10) | 2~5단계 설비 (4-1) |
| 가게 매입 | Lv15~ / 50,000 (보증금 1,000은 값에서 빼 줌) | 간판이 "내 가게"로 바뀜 | 월세 없음. 장기 목표 — 기획안 |

**월세 규칙 (확정 방식, 금액 기획안):**
- **접속 10분마다 60코인** (분당 6). 접속 안 한 동안은 안 냄 — 알바생 급여와 같은 규칙. 코인에서 자동으로 빠짐.
- **못 내면 가게 문이 닫힘**: 셔터가 내려가고 진열대 손님·알바생·기계가 멈춤. **가게 앞 노점 자리에서는 계속 손으로 만들어 팔 수 있음**(쟁반 5칸, 노점 수요). 코인이 생기면 밀린 월세 1번을 내고 바로 다시 열림. 가게를 빼앗거나 빚이 쌓이지는 않음.
- 금액 감각: Lv3 무렵 손 제작 순이익이 분당 약 25 → 월세는 그 4분의 1 정도. 국자 2개 + 알바생 1명이면 분당 약 40이라 월세를 내고도 남음. Phase 5 시뮬레이터로 확인.
- 노점일 때 진열은 쟁반 5칸, 보관함(30)은 그대로.

### 4-1. 단계 (외형 순서 확정, 수치 기획안)

| 단계 | 해금 Lv / 비용 | 설비 | 생산 | 품질 | 외형 상태 |
|---|---|---|---|---|---|
| 1 | Lv1 무료 | 전통 연탄 화로 + 국자 (손 + 알바생) | 국자 1개당 1개 | 손 Burnt~Perfect / 알바 Normal~Good | 확정 (만듦) |

### 4-3. 손 작업대와 기계의 관계 (D10 — 확정, 2026-11-19)
문서끼리 다르다: `MACHINE_ERAS.md`는 "작업대의 화로 자리가 다음 시대 기계로 바뀌고 플레이어 도구도 바뀜(손맛 차이)", `SHOP_GROWTH_PLAN.md`는 "각 단계 설비가 이전 설비를 대체하는 자동 생산"이다.

다른 타이쿤 조사 (사용자 요청): Restaurant Tycoon 2는 직원을 두어도 플레이어가 계속 직접 요리할 수 있고(직원은 다른 일을 맡음, 셰프는 플레이어가 요리하는 것을 보며 배움), Chocoblox Factory Tycoon은 "기계 자리"를 사고 거기에 기계를 넣어 옛 기계와 새 기계가 같이 일한다. 자동화만 하고 보상이 없으면 플레이어가 아쉬워한다는 반응도 있었다. (출처: [Restaurant Tycoon 2 소개](https://screenwiseapp.com/media/restaurant-tycoon-2-game), [Chocoblox Factory Tycoon v1.0 개발 노트](https://devforum.roblox.com/t/chocoblox-factory-tycoon-v10-biggest-update-ever/1884479), [자동화 보상 의견](https://itch.io/post/8626482) — 팬 위키·개발 노트 수준이라 세부는 달라졌을 수 있음)

**확정:**
1. **손 작업대(연탄 화로 + 구리 국자)는 끝까지 남는다.** 시대가 바뀌어도 플레이어가 손으로 만드는 곳은 그대로라 핵심 재미와 Perfect 경로가 지켜진다.
2. 2~5단계 기계는 가게 안 **기계 자리 1곳**에 놓이고, 다음 단계를 사면 그 자리 기계만 바뀐다 ("이전 설비를 대체").
3. 1단계 국자·알바생은 기계를 사도 **그대로 남아 일한다** (노점이 살아 움직이는 모습 + 2단계가 1단계 최대치보다 생산이 적어지는 문제를 막음).
4. 알바생은 플레이어가 손으로 만드는 것을 보며 숙련도가 오른다 (4-2).
5. 시대별로 손 도구·손맛이 바뀌는 안(`MACHINE_ERAS.md`)은 꾸미기용 "작업대 스킨"으로 출시 후에 검토.

## 8. 뽑기 (D2)
- 이 게임의 차별점 (기획 대화 결론). 만든 달고나를 바늘로 선 따라 떼어 냄. — 확정 방향
- **선택형 도전 — 확정 (사용자, 2026-11-21, D22):**
  - **성공 = 덤.** 성공하면 같은 달고나(도안·등급·품질·가격 그대로)를 **1개 더**, 완벽(금 0, 정확도 0.9 이상)하면 **2개 더** 보관함에 넣어 줌. 재료·젓가락은 안 씀. 덤은 포장 안 된 상태(포장 ×1.1은 방금 만든 원본만). 보관함이 차면 들어가는 만큼만.
  - **실패(쪼개짐) = 못 팖.** 그 달고나는 보관함에서 빠짐.
  - 사용자가 고른 이유: 세 안(덤 / 뽑은 모양 진열 / 즉시 상금) 중 "덤 하나 더".
  - 결과 화면 "완벽 뽑기!" 배지, 도감 기록.
  - 확인할 점(기획안): 성공하면 한 판에 2~3개가 나와 손 제작 생산이 늘어남. 손님 수요(5-1) 안에서는 괜찮지만, 실패하면 한 개를 통째로 잃으니 "할까 말까" 고민이 생김 — 의도대로인지 손맛 테스트에서 봄.
- 난이도: 도안 선 길이·곡률, 누르기 두께(얇을수록 어려움). — 기획안
- 아직 안 만듦. **MVP(Phase 1 끝)에 넣음 — 확정 (D2).**
- 다른 플레이어와 하는 "뽑기 대결"은 출시 후.
