## 0. 한 줄 정의

> 한국 레트로 골목의 내 달고나 가게에서, 연탄불 위 구리 국자로 설탕을 녹이고 소다로 부풀려 붓고 눌러 모양을 찍어 **손으로** 달고나를 만든다. 손님 NPC가 와서 사 가고, 그 돈으로 국자와 알바생을 늘리고, 시대별 달고나 기계를 거쳐 공장까지 키운다.

| 항목 | 내용 | 상태 |
|---|---|---|
| 플랫폼 / 장르 | Roblox / 제작 미니게임 + 타이쿤 + 수집 | 확정 |
| 이름 | **달고나 골목 (Dalgona Alley)**. 문서 일부에 남은 "Dalgona Tycoon"은 옛 가제 | 확정 (D15) |
| 제작 방식 | 미니게임 중심, 직접 손으로 | 확정 |
| 카메라 | 3인칭. 제작 중에는 단계마다 작업대를 가까이 비추는 고정 카메라 | 확정 (만듦) |
| 판매 | NPC 손님이 자동으로 와서 진열된 재고를 삼 | 확정 |
| 재미 비중 목표 | 직접 제작 40 / 가게 성장 40 / 수집·꾸미기 20 | 기획안 |
| 기기 | PC + 폰 (가로). 모든 조작은 탭·누르기·드래그 | 확정 (만듦, 폰 재확인 남음) |

### 지키는 원칙
1. **손으로 만드는 것이 이 게임의 중심이다.** 자동화(알바생·기계·공장)는 양과 편의를 주고, **Perfect(1.7배)와 최고 도안은 손으로만** 나온다. — 확정 원칙 (`SHOP_GROWTH_PLAN.md` 0장, 사용자 대화)
2. **숫자만 바뀌는 미니게임 금지.** 조작 결과가 국자 속 설탕, 반죽, 달고나 모양으로 눈앞에서 바뀌어야 한다. — 확정 (만듦)
3. **돈으로 제작을 건너뛰게 하지 않는다.** (10장) — 확정 원칙
4. 돈이 무한히 늘지 않게: 재료, 창고, 손님 수요가 생산을 묶는다. — 기획안 (7장)
5. 코인·재고·품질은 서버가 정한다. — 확정 (만듦: 제작 점수 서버 재계산)
6. 실제 상표·오징어 게임 IP는 쓰지 않는다. 달고나 뽑기는 전통 놀이라서 쓴다. — 확정

## 2. 제작 미니게임 (만든 그대로)

작업대 앞에서 E(폰은 버튼) → 나무젓가락 고르기 → 도안 고르기 → 6단계 → 결과 화면. — **확정 (만듦)**

### 2-1. 작업대 구성 (만듦)
연탄 화로 + 철망(사용자 모델, 연탄은 한 판마다 0.1씩 닳고 다 타면 다음 판에 새 연탄. ~~비용 없음~~ → D44(11-24): 연탄은 재료 상점에서 사고, 다 타면 보관한 연탄 1장을 갈아 넣음), 구리 국자(사용자 모델, 플레이어 아바타의 오른팔이 손잡이를 잡음), 나무젓가락(포장지를 찢고 쪼개는 연출), 양은 설탕 그릇·소다 깡통·숟가락, 검은 철판, 누름판, 도안 틀 23종.

### 2-2. 단계

| # | 단계 | 조작 (마우스 = 손가락) | 점수에 들어가는 것 | 실패 |
|---|---|---|---|---|
| 0 | 젓가락 고르기 | 포장지 찢기 → 젓가락 쪼개기 (연출) | — | — |
| 0 | 도안 고르기 | 23종 중 고름 (지금은 전부 열림) | 가격 | — |
| 1 | 설탕 넣기 | 숟가락으로 그릇에서 떠서 국자 위에서 멈추면 기울어 쏟아짐. 백설탕 2 + 황설탕 1/4 | 정량에 가까움 + 흘린 양 | 흘리면 감점 |
| 2 | 녹이기 | 국자 안에서 원을 그리며 젓기(STIR SPEED). **화면 왼쪽 구역 위아래 드래그 = 국자 높이**(높이 막대, 폰은 두 손가락). 가루 → 결정 → 반쯤 녹음 → 투명한 액체 4단계 | 젓기 속도 적정 비율 + 온도 적정 비율 − 눌어붙음 − 탐 | 불에 너무 가까우면 빨간 경고 → **Burnt**(Q 20 이하로 끝) |
| 3 | 소다 | 젓가락 끝을 소다 깡통에 찍어 묻힘 → 국자 위에서 놓아 떨어뜨림(횟수 = 양) → 빠르게 저으면 실제 영상처럼 부풀어 오름 | 넣은 타이밍(다 녹고 2초 안 만점) + 양(알맞음 0.35~0.65) + 부푼 정도 | 너무 많음 = 진한 색·감점, 불 위에서 저음 = 탐 |
| 4 | 붓기 | 국자 손잡이를 끌어 철판 위 설탕 원으로 가져가 기울임. 점성 있는 줄기로 떨어짐. 길쭉하면 젓가락으로 양끝을 가운데로 모을 수 있음 | 원 가운데와의 거리 + 국자에 남은 양 + 모양(길이/폭) | 길이/폭 1.8 넘음 = **Fail**(틀이 안 맞음, Q 15 이하) |
| 5 | 누르기 | 누름판을 집어 반죽 위에서 가만히 누르고 있으면 내려감. 3번 나눠 누름. 누른 뒤 누름판이 비켜 눌린 원판이 보임 | 3번 모두 목표 두께(0.25 / 0.14 / 0.08) | 너무 얇음 = 가장자리 갈라짐 −35 |
| 6 | 모양 | 틀을 끌어 원판 가운데에 놓고 누름판으로 살살 짧게 누름. V자 홈 자국 | 중심 50% + 각도 20% + 누른 세기 30% | 너무 오래 누름 = 금 −20 |
| 7 | 뽑기 (선택) | 바늘로 선 따라 긁기. 언제든 "그만하고 팔기" | 따라간 비율, 금 개수 | 쪼개짐 → **못 팖** (보관함에서 빠짐) |

- 1~6단계: **확정 (만듦)**. 효과음 7개(사용자 고름), 단계별 카메라, 폰 레이아웃 포함.
- 7단계 뽑기: **MVP에 선택 단계로 넣기 확정 (D2)**, 만듦 (main, 서버 검증). 성공 보상·실패 규칙은 8장 (D22).
- 한 판 목표 시간 35~45초(뽑기 제외). 옛 문서의 20~35초는 버림. 실제 시간은 손맛 테스트(U2)에서 잼. — 기획안
- 도안별 난이도(도장 판정 폭, 뽑기 선 길이·곡률)는 아직 전부 같음. — 미정 (Phase 1 남은 일)

### 2-3. 품질 판정 (만듦, `src/shared/Scoring.lua`·`DalgonaConfig.lua`)

Q = 0.25T + 0.20M + 0.25P + 0.30S, T = 설탕 20% + 녹이기 80%, P = 붓기 30% + 누르기 70%. 정수로 반올림. 서버가 입력 기록으로 다시 계산하고 서버 점수를 씀(단계당 최소 1.5초).

| 등급 | Q | 가격 배율 | 상태 |
|---|---:|---:|---|
| Perfect | 95–100 | 1.7 | 확정 (만듦) |
| Excellent | 85–94 | 1.3 | 확정 (만듦) |
| Good | 70–84 | 1.0 | 확정 (만듦) |
| Normal | 50–69 | 0.8 | 확정 (만듦) |
| Poor | 30–49 | 0.5 | 확정 (만듦) |
| Burnt | 0–29 (탔으면 Q ≤ 20) | 0.2 | 확정 (만듦) |
| Fail | 모양 실패 (Q ≤ 15) | 0.2 | 확정 (만듦) — **옛 문서에 없던 등급, 이 문서에서 추가** |

- 별 3개: Q 50 / 70 / 85 이상. 판매가 = round(도안 가격 × 배율). — 확정 (만듦)
- 뽑기는 Q·판매가에 안 들어감. 성공하면 덤 달고나, 쪼개지면 못 팖 (8장, D22). 옛 "판매가 × (1 + 0.5 × 정확도)" 보너스는 없앰.

### 3-2. 도감 (기획안, Phase 4)
- 도안 × 최고 등급을 기록 (예: 별 — Excellent). 처음 만든 도안, 처음 Perfect, 처음 완벽 뽑기 때 결과 화면에 "도감 등록" 표시.
- 손으로 만든 것과 자동 생산은 따로 센다 (도감·랭킹은 손으로 만든 것만).
- **Master 해금 — 확정 (D6):** 레벨이 아니라 도감 조건. 손으로 Excellent 이상 만든 Mythic **종류 수** 1 / 2 / 3 → 거미 → 삼각형 속 삼각형 → 눈꽃, **연꽃 문양 = Mythic 3종 모두 손으로 Perfect**. 알바생·기계로 만든 것은 안 셈. Master는 자동 생산 불가. (2026-11-20 구현 세션과 맞춤)

## 4. 가게 성장 (야외 노점 → 월세 가게 → 알바생 → 시대별 기계 → 공장)

가게 확장은 **달고나를 만드는 방식이 시대에 따라 바뀌는 것**이다. 수치 근거는 `SHOP_GROWTH_PLAN.md`.

### 4-0. 야외 노점 → 월세 가게 → 기계 (확정 방향 2026-11-21, 수치 기획안, D21)

사용자 결정: **처음에는 야외에서 뽑기(달고나)를 팔고, 돈이 모이면 가게에 월세로 들어가고, 그다음에 기계를 산다.**

| 순서 | 언제 | 모습 | 할 수 있는 것 |
|---|---|---|---|
| 야외 노점 | Lv1, 무료 | **내 부지의 가게 건물 바로 앞**에 연탄 화로 작업대 + 파라솔 + 낮은 의자 + 달고나 쟁반. 건물은 셔터가 내려져 있고 "임대 문의" 종이가 붙어 있음 (확정: 자리) | 손 제작, 쟁반 진열 5칸, 손님은 30초 × 1개(5-1). 알바생·작업대 업그레이드는 안 됨 |
| 가게 임대 | Lv3 + **보증금 1,000** | 셔터가 올라가고 가게 안이 열림. 손 작업대는 **가게 앞 그 자리 그대로**(옛 가게처럼 화로는 문 앞), 가게 안 = 진열대 10칸·기계 자리 (화로 알바생은 화로 옆) | 알바생(D34)·진열 알바(Lv5, D33)·작업대 업그레이드·Lv3·5·8 보상(D39). 수요는 레벨 구간 표(5-1) |
| 기계 | Lv10~ (가게 임대 중이어야 함) | 가게 안 기계 자리 1곳 (D10) | 2~5단계 설비 (4-1) |
| 가게 매입 | Lv15~ / 50,000 (보증금 1,000은 값에서 빼 줌) | 간판이 "내 가게"로 바뀜 | 월세 없음. 장기 목표 — 기획안 |

**월세 규칙 (확정 방식, 금액 기획안):**
- **접속 10분마다 60코인** (분당 6). 접속 안 한 동안은 안 냄 — 알바생 급여와 같은 규칙. 코인에서 자동으로 빠짐.
- **못 내면 가게 문이 닫힘**: 셔터가 내려가고 진열대 손님·알바생·기계가 멈춤. **가게 앞 노점 자리에서는 계속 손으로 만들어 팔 수 있음**(쟁반 5칸, 노점 수요). 코인이 생기면 밀린 월세 1번을 내고 바로 다시 열림. 가게를 빼앗거나 빚이 쌓이지는 않음.
- 금액 감각: Lv3 무렵 손 제작 순이익이 분당 약 25 → 월세는 그 4분의 1 정도. 화로 알바생 1명이 붙으면 분당 약 35라 월세를 내고도 남음. Phase 5 시뮬레이터로 확인.
- 노점일 때 진열은 쟁반 5칸, 보관함(30)은 그대로.

### 4-1. 단계 (외형 순서 확정, 수치 기획안)

  합계 약 27시간으로 6장 목표(Lv25 ≈ 20~30시간) 안. 2단계는 옛 수요(7.5)면 늘어난 판매가 +2.5뿐이라 회수 6시간 → 첫 기계가 너무 약해서 10초 × 1~2(분당 9)로 올림.

## 8. 뽑기 (D2)
- 이 게임의 차별점 (기획 대화 결론). 만든 달고나를 바늘로 선 따라 떼어 냄. — 확정 방향
- **선택형 도전 — 확정 (사용자, 2026-11-21, D22):**
  - **성공 = 덤.** 성공하면 같은 달고나(도안·등급·품질·가격 그대로)를 **1개 더**, 완벽(금 0, 정확도 0.9 이상)하면 **2개 더** 보관함에 넣어 줌. 재료·젓가락은 안 씀. 덤은 포장 안 된 상태(포장 ×1.1은 방금 만든 원본만). 보관함이 차면 들어가는 만큼만.
  - **실패(쪼개짐) = 못 팖.** 그 달고나는 보관함에서 빠짐.
  - 사용자가 고른 이유: 세 안(덤 / 뽑은 모양 진열 / 즉시 상금) 중 "덤 하나 더".
  - 결과 화면 "완벽 뽑기!" 배지, 도감 기록.
  - 확인할 점(기획안): 성공하면 한 판에 2~3개가 나와 손 제작 생산이 늘어남. 손님 수요(5-1) 안에서는 괜찮지만, 실패하면 한 개를 통째로 잃으니 "할까 말까" 고민이 생김 — 의도대로인지 손맛 테스트에서 봄.
- 난이도: 도안 선 길이·곡률, 누르기 두께(얇을수록 어려움). — 기획안
- 아직 안 만듦. **MVP(Phase 1 끝)에 넣음 — 확정 (D2).**

## 9. 멀티플레이 (기획안)
- 스폰 = **내 가게 앞** (D25, 사용자 2026-11-21). 들어오면 바로 내 노점·가게 앞에서 시작.
- 서버 최대 6명. 가게 부지 6칸은 **길을 사이에 두고 3칸씩 마주 봄**: 남쪽 줄(앞이 북쪽)과 북쪽 줄(앞이 남쪽)에 3칸씩. 가게 번호는 **가운데부터 남·북을 번갈아** 채움 → 먼저 온 두 사람이 골목 가운데에서 마주 봄. 같은 줄 가게 간격 100, 가게마다 뒤에 공장 부지. 두 줄 가게 앞선 사이 길 폭 32, 길 양쪽에 턱(연석), 전봇대가 길 양쪽에 서고 전선이 길을 가로지름. 손님은 가게 앞 길로 다님. 입장 때 부지 배정, 퇴장 때 저장 후 반납. (D31, 2026-11-23 — 같은 날 처음 적은 "한 줄 6칸 + 건너편 장식 줄"은 두 줄 마주 보기로 바뀜)
- **꾸미기 가게는 골목 양 끝**(동·서 끝, 길 양쪽)에 2칸쯤씩 + 담벼락 + 골목 입구. 들어가거나 쓰지 않는 장식, 실제 상표 없이 가상 간판만. (D31)
- 골목 분위기 = **따뜻한 오후 낮**. 낮·밤이 바뀌지 않음. (D31)
- 처음 들어오면 골목 서쪽 끝 길 위(x 약 −190)에 섰다가, 가게를 배정받으면 **내 가게 앞**으로 옮겨짐 (D25 그대로).
- 다른 플레이어 가게를 걸어가 구경할 수 있음 (같은 골목). 남의 재고·설비는 못 만짐.
- 공장은 각자 가게 뒤에 붙어 있음 (4-5, D11). 다른 플레이어 공장도 구경 가능, 조작은 주인만.
- 출시 후: 친구 가게 방문 좋아요, 뽑기 대결, 랭킹(손 제작 / 자동 생산 따로), 중앙 광장·대회장.

### D34. 알바생 배치: 제작대마다 한 명 — 확정
사용자 원문: "알바생은 1,2,3,4단계 제작대 중 플레이어가 지정한 곳에서 달고나 제작하도록 하자. 기계 하나에 한 명씩. 플레이어가 제작 시작하면 해당 기계의 알바는 쉼." / 화로는 "국자 하나만".

- **제작대** = 1단계 손 작업대(연탄 화로) + 2·3·4단계 기계. 제작대마다 알바생 **한 명**. 알바생은 플레이어가 고른 제작대에서 그 제작대 방식으로 만든다 (화로는 국자로 40초에 1개, 기계는 그 기계 속도·개수).

### D47. 공장 대량 납품 — 상자에 담아 트럭으로 (2026-11-24, 확정, 기획만)
사용자 원문: "공장 열리고 이후에는 대량 납품도 넣자. 공장에 대량 납품시 상자에 담아서 공장 뒷문 열리면서 트럭이 뒤에 태우고 가는 걸로. 기획만 작성".

**확정 (사용자):** 공장(Lv25)을 연 뒤 **대량 납품**이 열린다. 납품하는 달고나는 **상자에 담기고**, 출고하면 **공장 뒷문이 열리면서 트럭이 뒤로 와서 싣고 간다.** 이번에는 기획만 (코드·3D는 나중).

**왜 필요한가 (기획 메모):** 5-1 표대로 5단계 손님 수요는 분당 30에서 멈추는데, 공장 업그레이드를 다 사면 생산은 분당 80을 넘는다. 남는 것은 보관함에 쌓이기만 함(D42). 대량 납품은 **손님 수요 밖의 두 번째 판매 통로**이자 Lv25 뒤의 목표("이번엔 500개 주문 끝내기"). 돈이 무한히 늘지 않게(SHOP_GROWTH_PLAN 8장) 주문 수·도매가로 막는다.

**기획안 — 주문**
- **납품 주문판**: 공장 제어대에 **[납품]** 탭 + 공장 출고장 벽의 칠판. 주문 **3칸**, 출고하면 그 칸은 **30분 뒤** 새 주문(시간당 최대 약 6건이 아니라, 채우는 데 걸리는 시간 때문에 실제로는 시간당 1~3건).
- 주문 하나 = 주문처 + 도안 + 최소 품질 + 수량 (+ 가끔 포장):
  | 주문처 (예) | 도안 | 최소 품질 | 수량 | 포장 |
  |---|---|---|---:|---|
  | 학교 앞 문방구 | Common·Uncommon | Normal | 100 | 없음 |
  | 동네 축제 | Rare·Epic | Good | 250 | 없음 |
  | 백화점 과자 코너 | Epic·Legendary | Excellent | 250 | **포장 필수** (⑤ 포장 알바 D30 또는 내가 직접 D45) |
  | 놀이공원 | 아무 도안 2종 섞어 | Good | 500 | 없음 |
  - 도안은 **해금한 것 중에서만**, Legendary까지 (자동 생산 한계 D13). 주문처 이름·그림은 레트로 골목 결로.
- **보상 (도매가)**: 1개당 = 도안 기본가 × 품질 배율 × **0.7** (손님한테 파는 값보다 쌈 — 한꺼번에 사 가니까) + 주문을 다 채우면 **완료 보너스 = 합계의 +20%** → 결국 손님가의 약 0.84배. EXP는 1개당 1(기계와 같음, 4-6) + 완료 보너스 100.
  - 예: 별 같은 Uncommon Good(손님가 약 22) 250개 → 22 × 0.7 × 250 = 3,850 + 770 = **4,620코인**. Legendary Excellent 500개면 약 3만.
  - 손님 판매(분당 30)는 그대로 두고 그 위에 더해지는 돈이라, 5단계 수입이 약 30~50% 늘어나는 정도로 맞춤 (시뮬레이터로 확인).

**기획안 — 채우기**
- 주문을 고르고 **[이 주문 만들기]** → 공장 제어대 도안이 그 주문 도안으로 바뀌고, 조건에 맞는 공장 생산물은 보관함 대신 **납품 상자**로 바로 감. 조건에 안 맞는 것(품질 미달 등)은 보통처럼 진열대 → 보관함.
- 보관함에 이미 있는 맞는 달고나도 **[보관함에서 넣기]** 로 옮길 수 있음 (손으로 만든 것도 됨, Perfect는 Excellent로 셈).
- **상자 1개 = 25개.** 25개 찰 때마다 출고장에 상자가 하나 쌓임(테이프 붙이는 소리, 상자에 도안 스티커). 500개 주문이면 상자 20개.
- 납품 상자는 **보관함(D42)과 따로** 셈 (주문 수량까지만 담김). D42의 "공장 받는 상자 +250"은 보관함 쪽 그대로.
- **자리 비운 동안(D29)**: 주문을 걸어 둔 채 나가면 공장 오프라인 생산(절반 속도, D42)이 납품 상자를 채움. **출고는 접속해서** 버튼으로(트럭 보는 재미). 다 찬 상자는 들어올 때까지 기다림.

**기획안 — 출고 연출 (약 10초, 건너뛰기 가능)**
1. 주문이 다 차면 출고장 상자 더미 위에 **[출고!]** 버튼 + 제어대에 알림.
2. 누르면 **공장 뒷벽 셔터가 덜컹거리며 위로 말려 올라감** (뒷문 = 가게에서 먼 쪽 끝, 4-5 배치 기준).
3. **파스텔 트럭**(민트 차체 + 분홍 짐칸, 옆에 달고나 그림과 "달고나 골목" 글씨)이 뒷길에서 "삑삑" 후진해 셔터 앞에 섬. 짐칸 문이 열림.
4. 상자가 출고장 롤러를 타고 짐칸으로 미끄러져 들어감 + ⑤ 포장 알바 미니미(있으면, 없으면 내 캐릭터)가 상자 2~3개를 직접 들어 싣는 동작. 화면에는 상자를 최대 8개만 그리고, 나머지는 이미 실린 것으로 (폰 성능).
5. 짐칸 문이 닫히고 경적 "빵빵", 트럭이 떠나며 뒷길 끝에서 사라짐. 셔터가 내려감.
6. 코인이 출고장에서 튀어 오르며 HUD로 날아감 + 주문판에 "납품 완료" 도장.
- 다른 플레이어도 근처에 있으면 그 공장의 트럭이 보임 (골목 구경거리). 트럭은 **출고 때만** 만들고 끝나면 지움.

**만들 것 (나중, 기획 메모)**
- 3D (3D 세션): 공장 뒷벽 **롤 셔터 문**(`tools/blender/factory.py`에 문 부품 추가, 위로 말리는 애니메이션은 코드로 여러 판 접기), **트럭**(새 `truck.py`, 파스텔 사탕 공장 그림체 2026-11-19와 같은 결), **납품 상자**(골판지 + 테이프 + 도안 스티커 자리), 출고장 롤러.

**효과 (모든 공정 공통 틀):** 1단계 판정 폭 **+30%** · 2단계 **+60%** + 공정별 도움 · 3단계 **성공 기준 80 → 60점, 40~59점이면 강화 효과 절반** + 공정별 도움.
| 공정 | 1단계 (3,000) | 2단계 (7,000) | 3단계 (15,000) |
|---|---|---|---|
| ① 설탕 넣기 (저울 멈추기) | 초록 칸 +30%, 시간 +1초 | 초록 칸 +60%, 바늘 20% 느려짐 | 기준 60점 + 바늘이 초록 칸에서 잠깐 머뭇거림 |

| ③ 붓기·찍기 (박자 탭 3번) | 박자 허용 시간 +30% | 허용 +60%, 박자 표시 고리 | 기준 60점 + 3번 중 2번 맞으면 성공 |
| ④ 식히기·검사 (금 간 것 2개 집기) | 집는 칸 +30%, 지나가는 속도 −15% | 칸 +60%, 금 간 달고나가 반짝임, 속도 −25% | 기준 60점 + 1개만 집어도 강화 효과 절반 |
| ⑤ 포장 (빵끈 끌어 묶기) | 끌기 범위 +30%, 시간 +1초 | 범위 +60%, 끄는 방향 화살표 | 기준 60점 + 두 번 끌기 → 한 번 |

- 다른 결정과: D45(미니게임 규칙·효과) 그대로, D30(알바 효과) 그대로. 부딪힘 없음.

### D53. 건설 모드 (확정)
사용자 원문: "건설 가능하게 하기 (기계나 가구 내가 원하는 곳에 배치할 수 있게)".
**확정 (사용자):** 기계·가구를 플레이어가 원하는 곳에 놓을 수 있다. → **D32 "고정 자리에 하나씩, 꾸미기 배치 모드 없음"을 바꿈** (D32의 "산 기계 모두 같이 돎"은 그대로).

**안 A — 가게 안 격자 배치, 작업대·공장 공정은 고정 (확정)**
- **옮길 수 있는 것**: 2·3·4단계 기계, 진열 가구(유리 진열장·걸이판·작은 탁자), 냉장고·서랍장, 계산대, 장식 가구(앞으로 꾸미기 상품: 의자·화분·전등·포스터 등).
- **고정**: 손 작업대(연탄 화로) — 제작 화면 카메라·연출이 작업대 기준이고, 고정해 둔 붓기·누른 모양(CLAUDE.md "고정")을 건드릴 위험을 없앰. 공장 공정 라인 — 공장 3D 한 덩어리(D30·D45 자리). 가게 문·뒷문(공장 문).
- **격자·회전**: 바닥 **2스터드 격자**에 맞춰 놓음, **90°씩 회전**. 물건마다 차지하는 칸(발자국)이 정해짐.
- **놓을 수 있는 범위**: **내 가게 건물 안 바닥**만 (Lv3 임대 뒤, 노점 때는 안 됨). 공장 방은 첫 버전에서 빼고 나중에(공정 자리는 고정, 장식만).
- **못 놓는 경우**: 다른 물건과 겹침, 벽 밖, 문 앞 2칸, **입구 → 진열 가구 앞 → 계산대로 가는 길(폭 4스터드)** 이 막힘. 놓으려는 자리가 빨간 윤곽이면 안 됨, 초록이면 됨.
- **저장**: `d.layout = { [물건 key] = { x, z, r } }` — 부지 기준 로컬 격자 좌표(정수) + 회전 0~3. 어느 부지(1~6)를 배정받아도 같은 배치. 서버가 겹침·범위·길을 다시 검사하고 저장. 처음 값 = 지금 고정 자리. **[처음 배치로]** 버튼.
- **알바·손님 경로**: 알바는 자기 제작대/진열 가구/계산대의 **"앞 칸"**(물건마다 정함)으로 감. 손님은 입구 → 진열 가구 앞 칸 → 계산대. 배치를 바꾸면 경로를 다시 계산(길 검사를 통과한 배치만 저장되므로 항상 갈 수 있음). 
- **진열 칸**: 칸은 진열 가구에 붙어 있음(61칸 = 진열장 4 + 걸이판 30 + 탁자 27, D42 그대로). 옮겨도 칸 수·채우는 순서는 그대로.
- **폰 조작**: HUD에 **[꾸미기]** 버튼 → 카메라가 가게를 위에서 비스듬히 내려다봄 → 물건을 **탭하면 선택**(테두리) → **끌면 격자를 따라 이동** → 아래쪽 큰 버튼 **[돌리기] [넣어 두기] [취소] [완료]**. PC는 R로 돌리기. 꾸미기 중에는 손님이 잠깐 들어오지 않고 알바는 제자리에서 멈춤(판매·생산은 계속 셈).
- **넣어 두기**: 물건을 가구 보관함에 넣을 수 있음. 넣어 둔 기계는 안 돎, 넣어 둔 진열 가구의 달고나는 보관함으로.
- **수익화(D14)**: 장식 가구는 꾸미기 상품으로 팔 수 있음 (성능 없음).

~~**안 B — 정해진 자리 몇 개 중 고르기**~~ (안 고름): 가게 안에 기계 자리 4곳·가구 자리 6곳을 두고, 물건을 자리끼리 바꿔 놓기만. 길·겹침 걱정 없고 만들기 쉬움. 대신 "내가 원하는 곳"의 자유가 적음.

~~**안 C — 작업대까지 완전 자유**~~ (안 고름): 작업대·공장 방 포함, 회전 자유(15°). 가장 자유롭지만 제작 화면·고정 기능을 다시 시험해야 하고, 폰에서 정밀 조작이 어렵고 버그 위험이 큼.

### D55. 주문 제작 손님 (확정)
사용자 원문: "주문 제작 손님 추가".
**확정 (사용자):** 특정 도안·품질(·포장)을 주문하고 기다리는 손님을 넣는다.

**확정 (아래 수치 포함, 사용자 11-25 권장안):**
- **누가**: 새 손님이 아니라 **손님 7종(D37)이 가끔 주문서를 들고 옴**. 주문 내용은 그 손님 취향을 따름:
  | 손님 | 주문 도안 | 최소 품질 | 포장 | 개수 |
  |---|---|---|---|---:|
  | 아이 셋 (퐁퐁이·설기·도토리) | Common·Uncommon 중 하나 | Normal | 없음 | 1 |
  | 단골 둘 | 좋아하는 도안 (하트 2 전이면 열린 도안 중 무작위) | Good | 가끔 | 1~2 |
  | 뽀글이 | Rare 이상 | Good | **있음** | 1~2 |
  | 부엉이 (Lv15~) | Legendary 이상 (Mythic도 → 손으로만) | Excellent | **있음** | 1 |
- **빈도**: 가게 임대(Lv3) 뒤. **동시에 1명**, 주문이 끝나면(채우거나 떠나면) **약 3분(±30%) 뒤** 다음 주문 손님. 접속 중에만.
- **기다리기**: 계산대 옆 **주문 대기 의자**에 앉고, 머리 위 말풍선에 도안 그림 · 품질 별 · 포장 아이콘 + 줄어드는 시계. 기다리는 시간 **3분**, Epic 이상·포장 주문은 **+1분**. 동시 손님 3명(5-1)에는 **안 셈**(앉아 있으니 길을 안 막음, 폰 부담은 모델 1명 더).
- **건네기**: 주문 손님을 탭 → 맞는 달고나 고르기 → 건넴. 계산 알바(D43)가 있으면 **맞는 게 생기는 순간 알바가 자동으로 건넴**.
- **보상**: 판매가 **×1.5** — 주문 전에 만들어 둔 것(진열대·보관함)은 **×1.3** (Perfect면 ×2 / ×1.7) + 손님 종류 팁(아이 0 / 단골 +10% / 뽀글이 +15% / 부엉이 +30%) + **EXP 20** + 그 손님 하트 판매 수 **+3**(D38, 주문 한 번이 3개 판 만큼).
- **실패**: 시간이 지나면 "아쉽다…" 하고 떠남. **벌 없음**(돈·하트 안 깎음). 다음 주문 손님은 똑같이 3분 뒤.
- **자동 생산과**: 알바·기계가 만든 것도 조건만 맞으면 됨. Mythic 주문(부엉이)은 손으로만 만들 수 있어서 손 제작 이유가 됨.
- **D47 대량 납품과 차이**: 납품 = 공장(Lv25) 뒤, 100~500개, 시간 제한 없음, 도매가(손님가 70% + 20%), 트럭 출고. 주문 손님 = Lv3부터, 1~2개, 몇 분 안, 손님가보다 비쌈(×1.5), 손 제작·진열 위주.
- 수요(5-1)와 돈: 주문은 3분에 한 번 1~2개라 분당 판매는 약 +0.5개. 대신 값이 높아 초반(Lv3~9)에 손 제작 수입이 약 15~25% 늘어남 — 시뮬레이터로.
- 저장: 주문은 접속 중에만 있어서 저장하지 않음 (`d.custDex` 하트 판매 수만 저장).

**질문 (답 받음: ①)**: 주문 전에 만들어 둔 것(진열대·보관함)도 건넬 수 있게 할까?
- ① 됨 — 맞는 게 있으면 바로 건넴 (권장: 보관함·진열을 미리 다양하게 채워 두는 재미, 계산 알바 자동 건네기와도 맞음. 대신 3분 대기가 거의 안 쓰이면 "주문 제작" 느낌이 약해서, 진열대·보관함 것은 ×1.3, 주문 뒤 새로 만든 것은 ×1.5)
- ② 주문을 받은 뒤 새로 만든 것만 — "주문 제작" 느낌이 강하지만, 손이 바쁠 때 놓치기 쉬움.

- **골목 배치**: 동쪽 끝 꾸미기 가게 2칸 중 1칸 → 골목 슈퍼(D31 바뀜), 문은 길 쪽. 가게 안 바닥 격자 범위를 부지마다 같은 로컬 좌표로.

## 16. 계산 (D56, 2026-11-25 확정)
사용자 원문: "지금은 진열하면 손님들이 알아서 사가는데 계산 기능 추가".
**확정 (사용자):** 손님은 진열대에서 달고나를 **집어 카운터 앞(`CustomerSpot`)에 줄을 서고**, **플레이어가 카운터에서 계산해야 코인이 들어온다.** (지금: 진열대 앞에서 고르면 바로 팔림.)

**사용자 답 (11-25): Q1·Q2 모두 권장안** — 카운터에서 [계산] 한 번(1초 연출), 선 지 5초 안이면 팁 +5% / 줄 최대 4명, 45초 기다리면 달고나를 돌려놓고 떠남(벌 없음), 손으로 만드는 중에는 절반 속도. 아래 안 A 전체를 확정 (계산 알바 자동 계산, 노점 줄 2명, 주문 손님은 건네기 = 계산 포함).

**안 A — 탭 한 번 계산 + 빨리 하면 팁 (확정)**
- **흐름**: 손님이 진열대에서 고름 → 고른 달고나를 손에 들고(진열 칸은 비고 "찜" 표시) → 카운터 앞 줄 → 플레이어가 카운터 뒤에 서면(또는 카운터 근처 버튼) 맨 앞 손님 머리 위에 **[계산]** → 탭 → **약 1초 연출**: 동전 짤랑 + 달고나를 종이봉투에 쏙 + 손님 인사 → 코인 들어옴, 손님 먹으며 나감.
- **빨리 계산 팁**: 맨 앞에 선 지 **5초 안**에 계산하면 **팁 +5%** (말풍선 하트). 2~4개 산 손님도 한 번 탭.
- **줄**: 카운터 앞부터 뒤로 **최대 4명**. 줄이 꽉 차면 새 손님은 진열대 앞에서 기다림(안 들어오지 않음, 5-1 수요 그대로).
- **기다리다 떠나기**: 손님마다 **45초** 인내 게이지(머리 위 작은 막대, 초록 → 노랑 → 빨강). 다 되면 "너무 오래 걸려…" 하고 **달고나를 진열대에 돌려놓고 떠남** — 판매 없음, 벌(돈·하트 깎기)은 없음.
- **손으로 만드는 중이면**: 제작 화면에 있는 동안은 인내가 **절반 속도**로 줄어듦(한 판 약 40초 → 약 20초만 줄어듦). 결과 화면 뒤 "손님 n명이 기다려요" + 카운터 쪽 화살표. 손 제작과 계산 사이를 오가는 바쁜 가게 느낌, 그래도 한 판 때문에 손님을 다 놓치지는 않음.
- **노점(Lv1~2)**: 카운터가 없어서 **작업대 옆 쟁반 앞**에 줄(최대 2명), 같은 [계산].
- **계산 알바 (D43, Lv6)**: 있으면 **자동 계산**(손님마다 0.8초) + 팁 +5%(D43 그대로). 그래서 D43의 계산 알바 효과는 "손님 수요 +10% · 팁 +5%" → **"자동 계산 · 팁 +5% · 수요 +10%"**. 계산 알바가 있어도 플레이어가 먼저 탭하면 플레이어가 계산(빨리 계산 팁은 알바 팁과 겹치지 않음, 둘 중 큰 것).
- **단계가 오를수록**: 2단계 분당 4.5명 분량은 손으로 충분, 3단계(분당 9) 이상은 손으로 따라가기 어려움 → **계산 알바가 사실상 필수**가 되는 지점(3번째 고용 3,000, Lv6)과 맞음.
- **자리 비운 동안(D29)**: 판매는 원래 없음 → 그대로. 기계·공장·알바가 만든 것(D32)은 지금처럼 진열대 → 보관함으로, 팔릴 때 계산만 거침.
- **주문 손님(D55)**: 줄을 서지 않고 주문 대기 의자에서 기다림. **건네기 = 계산**(건넬 때 코인 들어옴). 계산 알바는 맞는 게 있으면 건네기까지 자동(D55 그대로).
- **대량 납품(D47)**: 계산 없음(트럭 출고 때 정산).
- **다른 플레이어**: 남의 가게 카운터는 계산 못 함(구경만).

~~**안 B — 버튼만, 손님은 안 떠남**~~ (안 고름): [계산] 탭만 있고 팁·인내 없음. 줄이 꽉 차면 새 손님은 진열대 앞에서 기다림. 쉽고 놓치는 손님이 없지만, 긴장·보상이 없어 "할 일 하나 더"가 됨.

~~**안 C — 거스름돈 미니게임**~~ (안 고름): 손님이 낸 돈(예: 50원짜리 동전 3개)에서 거스름돈 동전을 골라 건넴, 맞으면 팁. 레트로 느낌은 가장 좋지만 손님이 많아지면(분당 9 이상) 지침 → 계산 알바 전까지만, 또는 2개 이상 산 손님만.

**구현 나누기 (기획 메모)**: 서버(SalesService) — 고르면 "찜" → 줄 → 계산 요청 시 판매 처리(지금 고르면 바로 팔던 부분을 계산 때로 옮김), 인내 45초(제작 중 절반), 빨리 계산 팁, 계산 알바 자동. UI — 맨 앞 손님 [계산] 버튼, 인내 막대, "손님 n명이 기다려요" 알림. 손님 모델(npc) — 달고나 들고 줄 서기·봉투 받기·실망하고 나가기 동작. 수치는 `GrowthConfig.Checkout = { queueMax = 4, patience = 45, makingSlow = 0.5, fastTip = { within = 5, mult = 0.05 }, cashierSeconds = 0.8 }`.
