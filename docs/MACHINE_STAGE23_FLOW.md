# 2·3단계 기계 작동 순서

2026-11-28 기준 main(`e7e0292`) 코드와 기획서(GDD D35·D41·D46·D60~D63)를 맞춰 정리했다.
코드: `src/client/MachineMake.lua`(화면 순서), `src/client/MachineMakeScene.lua`(장면), `src/shared/MachineMakeRules.lua`(점수·검사),
`src/server/Services/MachineMakeService.lua`(시작·제출), `src/server/Services/MachineService.lua`(알바 자동 생산).

## 1. 한눈에

| | 2단계 철제 판매기 | 3단계 분홍 자판기 |
|---|---|---|
| 열리는 때 · 값 | Lv5 · 5,000 | Lv15 · 45,000 |
| 한 판 개수 (금형판 칸) | 2개 | 5개 |
| 설탕 받기 | 배출구를 **꾹 눌러** 게이지를 초록 칸에서 멈춤 (실력) | 국자를 **왼쪽 기둥** 아래에 대면 정량 (약 1.5초) |
| 소다 | 젓가락으로 소다통을 **찍어** 넣음 (실력) | 국자를 **오른쪽 기둥** 아래에 대면 정량 (약 1초) |
| 녹이기 카메라 | 손 작업대 카메라 그대로 (국자를 따라감) | 컵을 앞에서 들여다보는 장면 카메라 |
| 직접 만들기 길이 (목표) | 약 25~28초 | 약 40초 이하 |
| 알바가 돌릴 때 | 30초에 2개 | 50초에 5개 |

## 2. 들어가기

1. 가게 안 그 기계 앞에 가면 안내(`MachinePrompt`)가 뜬다 → 누르면 **기계 창**이 열린다.
2. 기계 창에서 **이 기계가 만들 도안**을 고른다 (Legendary까지). 도안을 안 골랐으면 시작이 안 된다.
3. **[직접 만들기]** 를 누른다. 이 버튼은 그 기계 앞에서 연 창에서만 보인다.
4. 서버가 시작 조건을 본다. 하나라도 안 맞으면 시작하지 않고 이유를 띄운다:
   - 2·3단계 기계일 것 (4단계는 직접 못 씀)
   - 그 기계를 가졌을 것
   - 가게 문이 열려 있을 것
   - **그 기계에 알바가 없을 것** (D46 — 알바를 빼야 직접 씀)
   - 재료가 1개분 이상, 보관함 자리가 있을 것 → 만들 개수 = min(칸 수, 재료로 되는 수, 보관함 빈자리)
5. 시작하면 HUD·메뉴를 숨기고 걷기를 막는다. 카메라는 지금 자리에서 **가게에 놓인 그 기계 쪽으로 다가간다** (D60). 기계 크기는 가게에 놓인 그대로이고, 주변 가게는 그대로 보인다.

## 3. 직접 만들기 순서

화면 위 단계 표시: 동전 → 설탕 → 녹이기 → 소다 → 붓기 → 막대 → 누르기

| # | 단계 | 플레이어가 하는 것 | 2단계 | 3단계 | 점수 (2단계 / 3단계) |
|---|---|---|---|---|---|
| ① | 동전 | 기계 앞 동전 구멍을 **세 번** 누름 (100원 × 3). 동전이 투입구로 쏙 들어감 | 같음 | 같음 | 없음 |
| ② | 설탕 | 동전을 다 넣으면 국자가 배출구 아래에 놓여 있음 | 배출구를 **꾹 누르고 있으면** 설탕이 나옴 (초당 0.42). 막대가 **초록 칸(0.72~0.95)** 에 오면 손을 뗌. 넘치면(최대 1.25) 감점 | 국자 손잡이를 끌어 **왼쪽 기둥 아래**(빛나는 고리)에 대고 있으면 약 1.5초에 정량이 다 나오고 멈춤. 떼면 멈췄다가 다시 대면 이어서 | 10% / **0%** (3단계는 댄 시간 ≥ 1.2초만 검사) |
| ③ | 녹이기 | 국자가 화구 위로 옮겨짐 → 젓가락으로 저어 녹임 | 손 작업대 `Steps/Melt` 그대로 (화구 = 열선) | 같음 (컵 안 열선) | 30% / 30% |
| ④ | 소다 | 다 녹으면 소다를 넣고 빠르게 저어 부풀림 | 젓가락으로 소다통을 찍어 넣음 → 빠르게 젓기 (손 작업대 `Steps/Soda` 그대로) | 국자를 **오른쪽 기둥 아래**에 대면 정량(0.5)이 톡 떨어짐 (약 1초) → 바로 빠르게 젓기 (찍기 없음) | 20% / 20% (3단계는 양 항목 늘 만점) |
| ⑤ | 붓기 | 화면 오른쪽 반투명 검은 판의 **칸을 꾹 누르고 있으면** 국자가 그 칸 위로 가서 기울여 부음 (초당 0.75). 칸이 85% 넘게 차면 다음 칸으로. 넘치지 않게 | 2칸 | 5칸 | 20% / 25% |
| ⑥ | 막대 | 막대 더미에서 막대를 끌어 칸마다 놓음 (칸을 바로 눌러도 꽂힘). 붓고 나면 국자는 화면에서 숨김 | 2번 | 5번 | 없음 (걸린 시간만 검사) |
| ⑦ | 누르기 | 넓은 누름판 하나로 금형판 전체를 **한 번** 꾹 누름. 누르는 동안 누름판이 투명해지고 반죽이 눌리는 모양이 보임. 막대가 초록 칸에 오면 손을 뗌 (목표 두께 0.08, 너무 얇으면 갈라짐 −35) | 같음 | 같음 | 20% / 25% |
| ⑧ | 완성 | 볼록하던 칸 반죽이 납작해지고 금형 모양이 찍힘 → 굳으면 막대째 떼어 올림 → 첫 칸 달고나를 화면 가운데에 크게 띄워 천천히 돌림 | 같음 | 같음 | — |

- 금형판 칸이 곧 모양이라 **모양 찍기·뽑기는 없다**.
- 녹이기나 소다 중에 **태우면** 그 뒤 단계 없이 끝나고 "앗, 까맣게 탔어요" → 이번 판은 탄 달고나 (Q 20 이하).
- 화면의 [나가기]를 누르면 그 판은 버리고 끝난다.

## 4. 끝난 뒤

1. 클라이언트는 점수가 아니라 **입력 기록**(단계 시각·설탕 양·녹이기/소다 표본·칸마다 채운 양·누른 두께)을 서버로 보낸다.
2. 서버가 순서·시간·표본을 검사하고 `MachineMakeRules`로 점수를 다시 센다. 기록이 이상하면 "기록이 이상해서 이번 판은 못 받았어요".
3. 품질 Q = 위 표의 단계별 가중치 합. 등급은 손 제작과 같은 기준.
4. 결과:
   - 만든 개수만큼 재료를 쓰고 진열대·보관함으로 간다.
   - **Perfect가 나오면 그중 1개만 Perfect**, 나머지는 Excellent (D41).
   - 판매가는 기계 값 그대로 — 손 제작 수제 ×1.5는 **안 붙음**.
   - EXP = 기계 1개당 EXP × 개수 + 판마다 5.
   - 도감에는 손으로 만든 것으로 한 번 셈 (그 판의 가장 좋은 등급).
5. 결과 창: "등급 · 완성도 N%" / "도안 N개를 만들었어요 (· Perfect 1개!)" → **[한 판 더]** (서버에 새 판, 조건 다시 봄) 또는 **[그만하기]** (카메라·HUD·걷기를 되돌림).

## 5. 알바가 돌릴 때 (자동 생산)

1. 기계 창에서 그 기계가 만들 도안을 고르고, 그 기계에 알바를 배치한다 (D34 — 알바가 없으면 기계는 멈춰 있음).
2. 가게 문이 열려 있고 플레이어가 접속 중이면 한 판씩 돈다: 판을 시작할 때 재료(설탕·소다)를 확인 → 2단계 30초 / 3단계 50초 뒤 2개 / 5개.
3. 다 만들면 진열대 빈 칸 → 없으면 보관함. 보관함이 차면 멈춘다. 알바 급여는 한 판 끝날 때 낸다.
4. 품질은 Normal~Excellent (Perfect 없음). Lv8 "기계 알바 교육"(1,800)을 사면 Good~Excellent.
5. 움직임 (D36, 돌아가는 동안에만):
   - 2단계: 화구가 빨갛게 달아오르고 국자 두 개가 살짝 흔들림, 견본판 불빛, 다 되면 "띵" + 달고나 2개가 미끄러져 나옴. 알바는 판매기 앞에서 국자 두 개를 번갈아 젓고 레버를 당김.
   - 3단계: 버튼 불빛이 차례로 깜빡, 컵 안 설탕이 녹아 차오름, 누름 손잡이가 내려감, 5개가 쟁반으로. 알바는 자판기 옆에서 버튼 누르기 → 컵 젓기 → 손잡이 누르기.
