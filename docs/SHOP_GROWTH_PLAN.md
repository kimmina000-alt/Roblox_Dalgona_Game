# 가게 성장 기획: 국자·알바생 → 시대별 설비 → 공장 (v1, 2026-11-19)

출처: 사용자가 ChatGPT와 나눈 추가 기획 대화(화면 녹화 2026-11-19 15:05, 75초)를 한 화면씩 읽고 정리했다. 대화는 질문 4개로 되어 있다.

1. 시대별 기계를 확장 단계로 정리하고, 공장 경제 수치까지 만들어 달라.
2. **사용자 결정:** 가정용 메이커는 빼고, 2·3·5단계는 사용자가 보낸 기계 사진을 쓴다. 1단계는 큰 연탄 화로에 국자를 늘리고, 남는 국자는 알바생이 맡는다.
3. 바로 게임을 만들 수 있게 단계별 레벨·비용·명칭을 정리해 달라 (**이 문서의 기준 수치**).
4. 개발은 어떤 순서로 하나 (11장).

질문 1의 답에 있던 레벨과 비용(Lv5·10·15·20 / 2,000~250,000)은 질문 3의 답이 대체했다. 이 문서는 질문 3의 수치를 쓰고, 질문 1에서만 나온 공장 설계(생산 방식, 원가, 제한)는 살렸다.

상태 표기는 개발 계획서와 같다. **확정** = 사용자가 정함, **기획안** = 대화에서 나온 값(플레이 테스트 전), **미정** = 결정 필요.

## 0. 한 줄 요약

가게 확장은 가게가 커지는 것이 아니라 **달고나를 만드는 방식 자체가 시대에 따라 바뀌는 것**이다. 연탄 화로에서 혼자 만들다가, 국자를 늘려 알바생을 쓰고, 기계를 들이고, 마지막에는 공장에서 제어대로 대량 생산한다.

- Lv1~8: 직접 만드는 재미 + 국자·알바생이 늘어나는 노점
- Lv10~20: 기계가 일을 일부 대신해 주는 편리함
- Lv25: 공장에서 대량 생산하는 타이쿤의 재미
- Lv25 이후: 생산 라인과 창고를 늘리는 장기 목표

### 꼭 지킬 원칙 (기획안, 강하게 권장)
- **공장·기계가 직접 제작보다 항상 효율적이면 안 된다.** 직접 제작은 **Perfect(1.7배)와 희귀 도안의 고수익**을 맡고, 알바생·기계·공장은 **판매량과 편의성(방치 수익)**을 맡는다.
- 그래서 알바생과 기계의 품질은 최고 Excellent까지만 나온다. **Perfect는 플레이어가 손으로 만들 때만** 나온다.
- 설비를 샀다고 돈이 무한히 늘면 안 된다. 재료가 없거나, 완제품 창고가 꽉 차거나, NPC가 사 가는 양보다 많이 만들면 생산이 멈추거나 재고가 쌓인다(8장).
- 시각적 성장 보상이 중요하다. 플레이어가 설탕을 녹이는 동안 옆 국자에서 알바생이 젓고, 다른 쪽에서 달고나를 누르는 모습이 보여야 노점이 살아 움직인다.

## 1. 전체 성장 단계 (기획안)

총 5단계, 플레이어 Lv1~25, 설비를 사는 성장 시스템이다. 비용은 모두 게임 코인이다.

| 단계 | 해금 레벨 | 설비 명칭 | 구매 비용 | 생산 방식 | 기본 생산량 / 시간 | 품질 범위 |
|---|---|---|---|---|---|---|
| 1 | Lv.1 | 전통 연탄 화로 | 무료 | 손 제작 + 알바생 | 국자 1개당 1개 | 손: Burnt~Perfect / 알바: Normal~Good |
| 2 | Lv.10 | 2단계 기계 (명칭은 2-1 참고) | 15,000 | 반자동 | 2개 / 30초 | Normal~Excellent |
| 3 | Lv.15 | 3단계 기계 (명칭은 2-1 참고) | 45,000 | 자동 | 5개 / 50초 | Normal~Excellent |
| 4 | Lv.20 | 연속 생산 설비 | 120,000 | 완전 자동 | 10개 / 60초 | Normal~Excellent |
| 5 | Lv.25 | 달고나 자동화 공장 | 300,000 | 제어대 기반 자동 생산 | 20개(최대 40) / 100초 | Normal~Excellent |

- 각 단계는 **이전 설비를 대체**한다. 쌓아 두는 게 아니라 새로운 생산 방식으로 바뀐다.
- 생산 시간은 그 수량을 **한 번에** 만드는 시간이다. 예: 공장 20개 / 100초 = 평균 5초에 1개.
- 기계가 좋아질수록 생산량만 늘면 안 되고, **시간당 생산량**도 좋아져야 다음 단계를 살 이유가 생긴다.
  - 시간당 생산량: 2단계 4개/분 → 3단계 6개/분 → 4단계 10개/분 → 5단계 12개/분.
- 화로·누르개·작업대 장비 업그레이드(개발 계획서 3장 14번, 화로 Lv마다 적정 온도 구간 +8% 등)는 이 설비 단계와 **따로** 산다. Lv2에 "기본 도구 업그레이드"가 열린다(가격은 기존 장비 가격).

### 2-1. 단계별 기계 외형 — 확인 필요 ⚠️
대화 안에서 2·3단계 기계 사진의 배치가 서로 다르다.

| | 질문 2에서 사용자가 보낸 사진 순서 | 질문 3 답의 배치 | 지금 Studio·`MACHINE_ERAS.md`(작업 브랜치) |
|---|---|---|---|
| 2단계 | 쇠 기계 (스테인리스 윗판 + 국자 2개, 빨간 몸통) | "캐릭터형 달고나 성형기" + 분홍 자판기 사진 | Lv2 1세대 철제 판매기 |
| 3단계 | 분홍 캐릭터 자판기 | "자동 달고나 성형 설비" + 빨간 옛 캔디 기계 사진 | Lv3 2세대 분홍 자판기 |
| 4단계 | (가정용은 제외) | "연속 생산 설비" (컨베이어 라인, 새로 채움) | Lv4 가정용 미니 메이커 ← **사용자 결정과 다름** |
| 5단계 | 공장 기계 속 (투명 설탕 통) | 달고나 자동화 공장 | Lv5 공장 |

**권장:** 사용자가 보낸 순서대로 **2단계 = 1세대 철제 판매기, 3단계 = 2세대 분홍 캐릭터 자판기**로 하고, 숫자(레벨·비용·생산량)는 위 표를 그대로 쓴다. 4단계는 가정용 메이커를 빼고 "연속 생산 설비(컨베이어)"로 바꾼다. `MACHINE_ERAS.md`와 Studio의 Lv4 가정용 모델도 이에 맞춰 고쳐야 한다. → 사용자 확인 필요 (작업 우선순위 문서 결정 D9).

## 2. 1단계 — 전통 연탄 화로 (시작 설비, 기획안)

처음에는 화로가 커도 국자는 하나다. 레벨이 오르면 국자를 더 사고, 늘어난 국자에 알바생을 배치한다. 1단계 안에서 국자를 늘리는 것은 **생산 슬롯 확장**이고, 2단계로 넘어가는 것은 **만드는 방식 자체의 변화**다. 둘을 구분한다.

### 국자 확장
| 해금 레벨 | 확장 항목 명칭 | 구매 비용 | 작업 슬롯 | 알바생 자리 |
|---|---|---|---|---|
| Lv.1 | 기본 국자 | 무료 | 1 | 0 |
| Lv.3 | 제2 작업 국자 | 300 | 2 | 1 |
| Lv.5 | 제3 작업 국자 | 800 | 3 | 2 |
| Lv.8 | 제4 작업 국자 | 1,800 | 4 | 3 |

- 첫 번째 국자 = **플레이어 전용**(플레이어가 직접 조작하는 국자는 항상 하나). 나머지 국자 = 알바생 전용.
- 국자 하나에서 한 번에 달고나 1개를 만든다. 국자는 장식이 아니라 실제 생산 슬롯이다.
- 플레이어는 알바생이 일하는 동안에도 직접 제작 미니게임을 계속할 수 있다.

### 알바생 고용 및 관리
| 항목 | 비용 |
|---|---|
| 첫 번째 알바생 고용 | 500 |
| 두 번째 알바생 고용 | 1,000 |
| 세 번째 알바생 고용 | 2,000 |
| 알바생 급여 | 30초당 3 (**실제로 일하는 동안만** 차감) |

- 알바생 자리는 국자를 사면 열리지만, 고용은 따로 돈을 낸다. 알바생은 국자가 있어야 배치된다.
- 급여는 오프라인일 때 빠지지 않는다 (초보자 부담 방지).
- 알바생도 **재료를 소비**한다 (설탕·소다·포장지).

| 알바생 | 제작 시간 | 제작 품질 |
|---|---|---|
| 기본 알바생 | 40초 | Normal~Good |
| 숙련 알바생 | 35초 | Normal~Good |
| 전문 알바생 | 30초 | Good~Excellent |

- 초기 개발은 **기본 알바생만** 만든다. 숙련도는 나중에 업그레이드로 붙인다.

### 플레이어와 알바생의 차이
| 항목 | 플레이어 | 알바생 |
|---|---|---|
| 설탕 넣기 | 직접 | 자동 |
| 녹이기 | 직접 조작 | 자동 |
| 소다 넣기 | 직접 | 자동 |
| 누르기 | 직접 | 자동 |
| 도안 | 직접 고름 | 지정한 도안 |
| 품질 | Perfect 가능 | Normal~Good |
| 제작 시간 | 숙련도에 따라 짧아짐 | 고정 |

알바생은 미니게임을 하지 않는다. 대신 국자를 젓고, 붓고, 누르는 동작이 보여야 한다 (0장 시각적 보상).

## 6. 5단계 — 달고나 자동화 공장 (Lv.25, 핵심 후반 콘텐츠, 기획안)

공장은 손으로 만드는 미니게임과 **완전히 다른 조작**이다. 공장에 들어가면 가운데 제어대가 있고, 제어대에서 생산 작업을 등록한다.

| 항목 | 내용 |
|---|---|
| 해금 레벨 / 구매 비용 | Lv.25 / 300,000 |
| 생산 방식 | 제어대 기반 자동 생산 |
| 기본 생산량 / 최대 | 20개 / 40개 |
| 기본 생산 시간 | 100초 (20개 기준) |
| 품질 범위 | Normal~Excellent (Perfect 없음) |

### 공장 이용 순서
1. **제어대 누르기**: 생산 관리 화면이 열린다.
2. **도안 고르기**: 가지고 있는(해금한) 도안 중 하나.
3. **생산 수량**: 설비가 지원하는 수량(20개 / 40개).
4. **생산 방식**: 일반 / 정밀 / 고속 (아래 표).
5. **생산 시작**: 재료와 코인을 빼고 생산 대기열에 넣는다.
6. **자동 생산**: 컨베이어에서 하나씩 만들어진다 (연출).
7. **완제품**: 재고 창고로 들어가고, NPC 손님이 사 갈 수 있다.

### 제어대 화면 (예시)
- 위: "FACTORY CONTROL" + 상태(ONLINE)
- ① 생산할 도안: 도안 카드 (예: 동그라미·별·하트)
- ② 생산 수량: 20개 / 40개
- ③ 생산 방식: 일반(기본 품질·기본 속도) / 정밀(품질↑·시간↑) / 고속(시간↓·품질↓)
- 아래: 예상 생산 시간, 예상 재료 소모 (예: 20개 일반 = 100초, 설탕 20회분 + 소다 20회분 / 20개 정밀 = 150초 / 40개 일반 = 160초, 설탕·소다 40회분)

### 생산 방식과 품질 (질문 1의 답)
| 생산 방식 | 생산 시간 | 품질 판정 | 특징 |
|---|---|---|---|
| 일반 생산 | 기본 | Normal~Good | 기본 수익 |
| 정밀 생산 | 1.5배 | Good~Excellent | 고급 도안에 유리 |
| 고속 생산 | 0.7배 | Poor~Good | 빠른 대량 판매 |

품질 배율은 기존 경제표 그대로: Burnt 0.2 / Poor 0.5 / Normal 0.8 / Good 1.0 / Excellent 1.3 / Perfect 1.7. 자동 생산은 Excellent까지만.

### 공장 제어대 업그레이드
| 업그레이드 | 효과 | 비용 |
|---|---|---|
| 대량 생산 모듈 | 생산량 20 → 30개 | 50,000 |
| 초대형 생산 모듈 | 생산량 30 → 40개 | 80,000 |
| 병렬 생산 라인 | 동시 작업 2개 | 100,000 |
| 고속 컨베이어 시스템 | 생산 시간 15% 감소 | 120,000 |
| 정밀 품질 제어기 | Excellent 확률 증가 | 150,000 |
| 자동 포장 시스템 | 포장 작업 자동화 | 100,000 |
| 대형 완제품 창고 | 재고 보관량 2배 | 80,000 |

- 생산 라인 수 = 동시에 돌릴 수 있는 작업 수. 한 번에 만드는 수량과 따로 관리한다.
- 참고: 질문 1의 답에는 "공장 확장 업그레이드"(라인 2개 50,000 / 라인 3개 100,000 / 대형 재료 창고 30,000 / 완제품 창고 40,000 / 고속 컨베이어 10% 60,000 / 정밀 성형 장치 80,000 / 포장 자동화 100,000)가 있었다. 질문 3의 표가 대체한다.

## 7. 공장 원가와 수익 (질문 1의 답, 기획안)

공장은 만든 수량만큼 재료를 쓰고, 생산 방식에 따라 비용이 더 든다. 재료 값은 `ECONOMY_BALANCE.md`와 같다 (설탕 10회분 30 → 1회분 3, 소다 10회분 10 → 1회분 1).

| 항목 | 1개당 비용 |
|---|---|
| 설탕 | 3 |
| 소다 | 1 |
| 포장지 | 1 |
| 공장 운영비 | 1 |
| **총 원가** | **6** |

예: Good 등급 Common 달고나를 10코인에 팔고 NPC가 다 사 간다면, 공장 20개 = 매출 200 − 원가 120 = **순이익 80 / 100초**.

## 8. 돈이 무한히 늘지 않게 하는 제한 (기획안, 구현 필수)
1. 재료가 모자라면 생산이 멈춘다.
2. 완제품 창고가 가득 차면 생산이 멈춘다.
3. NPC가 사 가는 속도보다 빨리 만들면 재고만 쌓인다.
4. 공장에는 유지비가 든다.
5. 설비가 늘수록 전력·운영비도 는다.

특히 **NPC가 살 수 있는 양보다 많이 만들면 수익이 바로 늘지 않는 구조**가 중요하다. (참고: 지금 경제표의 NPC 수요는 가게당 분당 약 3명이다. 공장 기본 생산 12개/분은 이보다 훨씬 많으므로, Phase 3 판매 시스템을 만들 때 수요 상한과 함께 시뮬레이션해야 한다.)

## 11. 개발 진행 방식 (질문 4의 답)

ChatGPT의 답: 기획서를 통째로 주고 "다 구현해 줘"라고 하지 말 것. 시스템끼리 엮여 있어 한 번에 만들면 오류 원인을 찾기 어렵다. **기획서 분석 → 개발 계획 → 기능 단위로 구현 → Studio 테스트 → GitHub 저장 → 다음 기능**을 반복한다. 핵심 제작이 재미없으면 공장·타이쿤을 잘 만들어도 게임 중심이 약해지므로, **먼저 달고나 제작이 재미있는지 검증**한다.

이 프로젝트는 이미 이 방식으로 하고 있다: `DEVELOPMENT_PLAN.md`(분석·계획), `WORK_PRIORITIES.md`(진행 현황표), 기능마다 브랜치 → 사용자 승인 뒤 main 머지, `WORKLOG.md`.

ChatGPT가 제안한 개발 순서와 지금 계획(6장)을 비교하면:

| ChatGPT 제안 순서 | 지금 계획 | 다른 점 |
|---|---|---|
| 1 기획서 분석·개발 설계 | 개발 계획서 v1 | 같음 (끝남) |
| 2 기본 환경(구조·입장·Plot·UI) | Phase 0 + Phase 2 일부 | 지금은 제작 프로토타입을 먼저 만들고 Plot은 Phase 2 |
| 3 달고나 제작 (핵심 재미 검증) | Phase 1 | 같음 (진행 중, 손맛 테스트 남음) |
| 4 경제·판매 | Phase 3 | 같음 |
| 5 성장 (레벨·도안·업그레이드·**국자 확장·알바생**) | Phase 4 | 국자·알바생을 Phase 4에 넣음 |
| 6 시대별 설비 확장·공장 | Phase 5 | Phase 5 = "직원" → "시대별 설비·공장"으로 바뀜 |
| 7 저장 | Phase 2 | **ChatGPT는 저장을 뒤에 둠. 지금 계획대로 Phase 2에 먼저 하는 것을 권장** — 코인·재고·설비가 모두 저장 위에 올라가고, 나중에 붙이면 데이터 구조를 다시 고쳐야 한다 |
| 8 맵·아트·튜토리얼·모바일·성능 | Phase 6~7 | 같음 |

코드 규칙(ChatGPT 10개)은 대부분 `DEVELOPMENT_PLAN.md` 8장과 CLAUDE.md에 이미 있다. 새로 더할 것:
- 이미 만든 기능을 마음대로 지우거나 다시 쓰지 않는다.
- 기능을 만든 뒤 기존 기능이 그대로 되는지 다시 확인한다 (회귀 테스트).
- 오류는 원인을 찾은 뒤 가장 작은 범위로 고친다.
- 끝나지 않은 것을 끝났다고 하지 않고, 테스트 안 한 것은 "테스트 안 함"으로 적는다.
- 기획서와 다르게 만들어야 하면 먼저 이유와 바꿀 안을 보고한다.

## 13. 아직 정할 것
- D9: 2·3단계 기계 배치와 4단계를 가정용 대신 연속 생산 설비로 할지 (2-1).
- 알바생이 만드는 도안: 국자마다 지정 / 가게 전체 하나 (기존 안: 플레이어가 작업대마다 지정, 기본값 가장 싼 해금 도안).
- 2·3단계 기계의 "반자동 / 간단한 조작"이 구체적으로 무엇인지 (예: 버튼 타이밍 한 번 → 품질 보너스).
- 기계 단계를 사면 1단계 국자·알바생은 어떻게 되는지 (대체되면 알바생 고용비를 돌려주는지, 알바생이 기계 옆에서 계속 일하는지).
- Lv10~25 구간 경험치 곡선과 플레이 시간 목표.
- 모든 숫자는 플레이 테스트 전 기획안이다.
