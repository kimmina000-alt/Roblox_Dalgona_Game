# 시스템 상세 설계

문서 상태: 대화 기반 초안 v1.0. 확정 방향과 제안 수치를 구분해 사용한다.

## 1. 플레이어 및 개인 가게
### 확정 방향
3인칭 캐릭터 조작. 각 플레이어는 독립된 가게(Plot)를 배정받는다.

### 제안 구조
- 입장 시 사용 가능한 Plot 할당.
- 데이터 로드 후 해당 Plot 초기화.
- 본인 가게의 장비/직원/재고만 관리 가능.
- 타 플레이어 가게는 방문 가능하도록 확장할 수 있다.
- 퇴장 시 데이터 저장 후 Plot 반환.

권장 Plot 모델:
- ShopModel
- Workstations: Stove, MixingTable, PressTable, StampTable
- CustomerEntrance, CustomerQueue, SalesCounter
- EmployeePositions, DecorationSlots

기본 조작 제안:
- WASD 이동, 마우스 카메라 회전, Space 점프, E 상호작용.
- 제작 UI 중에도 3인칭 정체성을 유지한다. 작업대 중심으로 카메라를 보조 조정할 수 있으나 1인칭 강제는 하지 않는다.

## 2. 제작 미니게임

> **2026-11-19 안내:** 아래 4단계(온도 게이지 등)는 옛 초안이다. 실제로 만든 6단계(설탕 넣기 → 녹이기 → 소다 → 붓기 → 누르기 → 모양)와 Fail 등급은 `GAME_DESIGN_DOCUMENT.md` 2장이 기준이다.
제작은 다음 4단계다.
1. 설탕 가열: 움직이는 온도 게이지의 적정 구간에서 입력.
2. 소다 혼합: 정해진 타이밍/횟수에 맞춰 입력.
3. 압착: 타이밍 또는 압력 게이지를 맞춰 두께를 결정.
4. 도장 찍기: 도안의 위치/각도/압착 깊이를 맞춰 각인.

제작 1회 목표 시간 제안: 약 20~35초. 플레이테스트로 조정한다.

### 점수 계산 제안
각 단계 0~100:
- T = 온도
- M = 혼합
- P = 압착
- S = 도장

Q = 0.25T + 0.20M + 0.25P + 0.30S

도장 정확도가 달고나 모양의 핵심이므로 가장 높은 비중을 준다.

### 품질 등급 제안
| 점수 | 등급 | 가격 배율 |
|---|---|---:|
| 0–29 | Burnt | 0.2 |
| 30–49 | Poor | 0.5 |
| 50–69 | Normal | 0.8 |
| 70–84 | Good | 1.0 |
| 85–94 | Excellent | 1.3 |
| 95–100 | Perfect | 1.7 |

심각한 실패(예: 설탕을 완전히 태움)는 총점과 별개로 제작 중단/Burnt 처리할 수 있다. 실패 규칙은 구현 전 확정 필요.

### 결과물 외형 제안
품질에 따라 색상, 표면 균일도, 탄 자국, 각인 선명도, 파손 효과를 다르게 적용한다. MVP는 하나의 기본 메시/모델에 색상과 표면 효과를 적용하는 방식이 효율적이다.

## 3. 제작 도구 에셋
- 국자: 둥근 얕은 금속 그릇 + 긴 손잡이 + 손잡이 끝 고리.
- 눌림판: 평평한 원형 금속판 + 손잡이, 가장자리는 bevel.
- 찍기 틀: 공통 손잡이/베이스와 도안별 각인 형상을 분리.
- 시각 스타일 제안: Roblox 저폴리곤, 레트로 한국 가게, 약간 사용감 있는 금속.

권장 파이프라인: Blender 모델링 → FBX 내보내기 → Roblox Studio 3D Importer → Tool/Model 구성 → 손잡이 기준 Pivot/Grip 설정 → 애니메이션과 상호작용 연결.
대화에서 제안한 초기 삼각형 수 목표: 국자 100~300, 눌림판 100~250, 찍기 틀 100~400(복잡 도안은 300~600). 이는 최적화 시작점이지 엔진 제한이 아니다.

## 4. NPC 자동 판매
### 확정 방향
NPC가 가게를 자동 방문해 재고를 구매한다. 플레이어가 직접 NPC에게 상품을 전달하는 방식은 MVP 기본 루프가 아니다.

### 초기 밸런스 제안
- 기본 방문 주기: 30초/손님 1명 (분당 2명)
- 판매 직원 배치 시: 20초/손님 1명 (분당 3명)
- 손님 1명 구매량: 1개
- 기본 재고 한도: 10개

### 판매 흐름
1. 손님 NPC 생성
2. 입구에서 대기 지점/판매대로 이동
3. 재고 확인
4. 상품 1개 구매
5. 서버가 상품 제거 및 코인 지급
6. 구매 애니메이션 후 퇴장

재고가 없으면 구매 없이 퇴장. MVP 상품 선택은 FIFO(먼저 등록된 상품부터 판매)를 제안한다. 추후 손님 취향/주문 유형을 추가할 수 있다.

### 수요와 생산 제한
생산량이 판매량보다 많으면 재고가 쌓인다. 재고 한도 도달 시 생산 중지. 재료 부족 시에도 생산 중지. 판매 후 빈 공간이 생기면 생산 재개.
동시 구매/중복 지급 방지를 위해 서버에서 재고 예약 및 판매 트랜잭션을 처리해야 한다.

## 5. 직원 시스템

> **2026-11-19 안내:** 아래 직원 등급표는 `SHOP_GROWTH_PLAN.md`의 국자 슬롯 + 알바생 안(고용 500/1,000/2,000, 30초당 3)으로 바뀌는 중이다 (결정 D3). 기준은 `GAME_DESIGN_DOCUMENT.md` 4장.
직원은 플레이어 직접 제작을 대체하지 않는 보조 시스템이다. MVP는 제조 직원부터 구현하고 포장/판매 직원은 후속 단계로 둔다.

직업 후보:
- 제조: 기본 도안 자동 생산
- 포장: 포장 시간 감소
- 판매: NPC 방문 주기 단축
- 매니저: 전체 효율 보너스
- 재료 담당: 재료 보충

직원 등급/생산 제안:
| 등급 | 생산 주기 | 분당 생산 근사치 | 급여/분 | 고용비 |
|---|---:|---:|---:|---:|
| Common | 90초 | 0.67 | 1 | 300 |
| Uncommon | 80초 | 0.75 | 1.5 | 1,000 |
| Rare | 70초 | 0.86 | 2.5 | 3,500 |
| Epic | 65초 | 0.92 | 4 | 10,000 |
| Legendary | 60초 | 1.00 | 6 | 30,000 |

위 표는 제조 직원 기준의 제안이다. 생산량은 정수 단위 생산 주기를 따르며, 분당 근사치는 장기 평균이다. 급여는 실제 근무 초에 비례해 누적 계산하는 것이 좋다.

제약:
- 접속 중에만 근무/생산/급여 발생.
- 재료와 재고 공간이 있어야 생산.
- 해금된 도안만 생산.
- Mythic은 직원 자동 생산 불가.
- 잔액 부족 시 근무 중지.
- 작업대/직원 슬롯 제한 필요.

직원 슬롯 제안: 가게 Lv1 1명, Lv3 2명, Lv5 3명, Lv10 4명, Lv15 5명, Lv20 6명.
직원 레벨업 및 개별 특성은 MVP 이후 확장.
