# MVP 개발 로드맵 및 테스트 계획

> **2026-11-19 안내:** 이 문서의 Phase 순서(기반 먼저)는 옛 안이다. 실제 순서는 `DEVELOPMENT_PLAN.md` 6장(제작 프로토타입 먼저)과 `WORK_PRIORITIES.md`. 제작은 4단계가 아니라 6단계다.

## 개발 원칙
기능을 작은 단위로 구현하고 각 단계가 Studio에서 정상 작동한 뒤 다음 단계로 진행한다. 기획 수치는 플레이테스트 후 조정한다.

## Phase 1. 기반
- [ ] Explorer 폴더/모듈 구조 구성
- [ ] PlayerDataService 기본 스키마/저장/로드
- [ ] PlotService 개인 가게 배정/해제
- [ ] 기본 HUD 및 코인 표시
- [ ] 소유권 검증

완료 조건: 입장 시 Plot 배정, 퇴장/재접속 후 코인과 진행 데이터 유지.

## Phase 2. 달고나 제작
- [ ] 작업대 E 상호작용
- [ ] 제작 세션 생성
- [ ] 가열 미니게임
- [ ] 소다 혼합 미니게임
- [ ] 압착 미니게임
- [ ] 도장 미니게임
- [ ] 서버 품질 판정
- [ ] 결과물 생성 및 재고 등록

완료 조건: 플레이어가 4단계 제작을 끝내고 점수/품질이 서버에서 결정된다.

## Phase 3. 재료/재고/NPC 판매
- [ ] 재료 구매 및 차감
- [ ] 상품 재고 한도
- [ ] NPC 스폰/이동/퇴장
- [ ] FIFO 판매
- [ ] 코인 지급
- [ ] 중복 판매/중복 지급 방지

완료 조건: 손님이 재고를 구매하고 정확한 코인이 한 번만 지급된다.

## Phase 4. 성장
- [ ] EXP/레벨
- [ ] 도안 해금
- [ ] 화로/누르개/작업대 업그레이드
- [ ] 경제 수치 검증

완료 조건: 성장 조건과 비용이 서버에서 검증되고 UI에 반영된다.

## Phase 5. 직원
- [ ] 직원 고용
- [ ] 제조 직원 자동 생산
- [ ] 근무 시간 기반 급여
- [ ] 재료/재고 한도 연동
- [ ] 잔액 부족 시 업무 중지
- [ ] 직원 슬롯 제한

완료 조건: 접속 중에만 생산/급여가 발생하며 재료와 재고가 올바르게 차감된다.

## MVP 테스트 체크리스트
| 테스트 | 기대 결과 |
|---|---|
| 여러 명 동시 입장 | 각자 다른 Plot |
| 재접속 | 데이터 유지 |
| 재료 부족 | 제작 시작 거부 |
| 제작 중 퇴장 | 잘못된 상품 지급 없음 |
| 잘못된 Remote 입력 | 서버 거부 |
| 재고 가득 참 | 추가 생산 중지 |
| NPC 손님 | 설정 주기대로 생성 |
| 재고 없음 | 코인 지급 없음 |
| 중복 판매 요청 | 보상 1회만 지급 |
| 급여 잔액 부족 | 직원 작업 중지 |
| 오프라인 | ~~생산/급여 없음~~ → D29: 알바생·기계·공장은 생산 (최대 8시간, 판매 없음) |
| 직원 생산 | 재료/재고 한도 준수 |

## 개발 지원 산출물 규칙
각 코드 변경은 다음을 포함한다.
1. 수정할 파일명/경로
2. 수정된 전체 코드
3. 변경된 부분 설명
4. Studio에서 실행할 테스트와 예상 결과
기존 코드가 있는 경우 전체 교체 전에 현재 파일을 읽고 기존 구조와 충돌을 확인한다.
