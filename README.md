# Dalgona Tycoon

한국 레트로 골목의 달고나 가게를 직접 운영하고 성장시키는 Roblox 타이쿤/시뮬레이터 프로젝트.

## 현재 확정된 핵심 방향
- 제작: 미니게임 중심
- 카메라: 3인칭
- 판매: NPC가 가게를 자동 방문해 재고를 구매
- 핵심 재미 비중(기획 목표): 직접 제작 40%, 가게 성장 40%, 수집·꾸미기 20%

## 문서 상태 규칙
- **확정**: 사용자가 명시적으로 선택한 사항
- **기획안**: 대화에서 제안된 값/설계. 아직 플레이테스트 전
- **미확정**: 결정 또는 검증이 필요한 사항
- 이 저장소는 현재 기획 단계다. 구현 완료를 의미하지 않는다.

## MVP 한 줄 정의
플레이어가 3인칭으로 개인 가게에서 국자·눌림판·도장을 사용해 달고나를 직접 만들고, 품질에 따라 상품화한 뒤 NPC 손님에게 자동 판매하여 코인을 벌고 가게를 성장시킨다.
